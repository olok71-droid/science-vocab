플로차트와 알고리즘 단원 시험이다.

알고리즘(algorithm) — 문제를 푸는 순서가 정해진 단계를 말한다.
단계는 애매하지 않게(unambiguous) 써야 하고, 언젠가는 끝나야(terminate) 한다.
같은 입력을 넣으면 같은 결과가 나와야 한다.

플로차트(flowchart) — 알고리즘을 그림 기호로 그린 것이다.
기호마다 뜻이 정해져 있으니 모양을 외워야 한다.
타원(oval, terminator) = 시작(Start)·끝(Stop/End).
평행사변형(parallelogram) = 입력/출력(input/output), 즉 INPUT 또는 OUTPUT/PRINT.
직사각형(rectangle) = 처리(process), 계산이나 값 넣기(예: total = total + 1).
마름모(diamond) = 판단(decision), 조건을 묻고 Yes/No 두 갈래로 나간다.
화살표(arrow, flow line) = 진행 방향이다.

순서·선택·반복(sequence, selection, iteration) — 알고리즘을 만드는 세 가지 구조다.
순서(sequence)는 위에서 아래로 한 번씩 차례로 실행한다.
선택(selection)은 마름모로 조건을 물어 갈라진다. 코드로는 IF … THEN … ELSE다.
반복(iteration/loop)은 화살표가 위로 되돌아가 같은 부분을 다시 돈다. 조건이 맞는 동안 도는 것이 WHILE, 정해진 횟수를 도는 것이 FOR다.
되돌아가는 화살표가 없으면 반복이 아니다 — 이 점을 그림에서 찾아내는 문제가 자주 나온다.

변수(variable) — 값을 담아 두는 이름이다.
반복 전에 total = 0, count = 0처럼 미리 값을 정해 두는 것을 초기화(initialisation)라고 한다.
초기화를 빼먹으면 답이 틀리므로 플로차트 빈칸 채우기에서 자주 묻는다.
카운터(counter)는 몇 번 셌는지 1씩 늘리는 변수(count = count + 1), 합계(total/running total)는 값을 계속 더해 쌓는 변수(total = total + number)다.

조건(condition) — 마름모 안에 들어가는 비교식이다.
비교 기호는 >(보다 큼), <(보다 작음), >=, <=, =(같음), <>(같지 않음)를 쓴다.
Yes 쪽과 No 쪽 화살표에 무엇이 붙는지 반드시 확인해야 한다. 두 갈래를 바꿔 쓰면 전체가 틀린다.

추적표(trace table) — 플로차트를 한 줄씩 따라가며 변수 값이 어떻게 바뀌는지 표로 적는 것이다.
표의 가로줄에는 변수 이름을 하나씩 두고, 값이 바뀔 때마다 새 줄에 적는다.
출력(OUTPUT) 칸은 따로 두고, 화면에 찍히는 값만 적는다.
머리로 계산하지 말고 한 칸씩 적어 내려가는 것이 정확하다.

의사코드(pseudocode) — 프로그램 언어 문법 대신 쉬운 영어로 알고리즘을 적는 것이다.
자주 쓰는 낱말: INPUT, OUTPUT/PRINT, IF … THEN … ELSE … ENDIF, WHILE … DO … ENDWHILE, FOR … TO … NEXT, REPEAT … UNTIL.
플로차트를 의사코드로 바꾸거나, 의사코드를 플로차트로 바꾸는 문제가 나온다.

자주 틀리는 것 — 처리(직사각형)와 입력(평행사변형)을 바꿔 그리는 실수가 가장 많다.
마름모에서 나가는 화살표가 두 개인지, 각각 Yes/No 라벨이 붙었는지 확인한다.
반복이 끝나는 조건이 없으면 무한 루프(infinite loop)가 되어 프로그램이 멈추지 않는다.
플로차트는 반드시 Start로 시작해 Stop으로 끝나야 한다.

✍️ 꼭 알아야 하는 것

  • 플로차트 기호 네 가지의 뜻 — 타원(시작·끝), 평행사변형(입력·출력), 직사각형(처리), 마름모(판단)를 모양만 보고 구분할 수 있어야 한다.
  • 추적표(trace table)로 플로차트를 한 줄씩 따라가며 변수 값과 출력값을 끝까지 적어낼 수 있어야 한다.
  • 선택(IF)과 반복(WHILE/FOR)을 플로차트와 의사코드 양쪽으로 바꿔 쓸 수 있어야 한다.

파이썬의 출력(print)·입력(input)·변수·문자열 합치기를 배우는 자료다.

출력(output)
파이썬에서 화면에 글자를 띄우는 명령은 print()다.
괄호 안에 들어 있는 내용이 화면에 그대로 나온다.
글자(텍스트)를 띄우고 싶으면 반드시 따옴표로 감싸야 한다. 예: print("Bob")
자료의 정의로 output은 컴퓨터에서 사용자에게 나가는 값(values sent from the computer to the user)이다.

입력(input)
사용자에게 무언가를 물어보고 받아 적게 하는 명령은 input()이다.
input은 컴퓨터로 들어오는 값(values sent from the user into the computer)이다.
print와 input의 가장 큰 차이는 이것이다. print는 그냥 메시지를 보여주기만 한다(just displays a message). input은 메시지를 보여주고 사용자가 뭔가 칠 때까지 기다린다(displays a message and waits for a user input).

변수(variable)
사용자가 친 값을 나중에 쓰려면 어딘가에 담아 둬야 한다. 그 담아 두는 자리가 변수(variable)다.
자료의 정의로 변수는 입력이 저장되는 곳, 즉 메모리 저장 공간(memory location / storage area)이다.
그래서 input문은 변수와 '='로 이어 줘야 한다. 예: answer = input("...")
이렇게 하면 answer라는 변수에 사용자가 친 값이 들어가고, 그 뒤에 print(answer)로 그 값을 다시 꺼내 화면에 띄울 수 있다.

문자열(string)과 따옴표(quotes)
프로그래밍에서 글자는 문자열(string)이라 부른다. 문자열은 키보드 문자들로 이루어진 자료형(data type)이다.
변수는 그 문자열을 담을 수 있는 저장 공간이다.
따옴표가 있고 없고가 완전히 다른 뜻이 된다. print("Bob")은 화면에 Bob이라는 글자를 그대로 띄운다. 그런데 따옴표를 빼고 print(Bob)이라 쓰면 파이썬은 Bob이라는 이름의 변수를 찾아 그 안의 내용을 띄우려 한다. 그런 변수가 없으면 에러(error)가 난다.

이어 붙이기(concatenation)
문자열과 변수를 이어 붙여 한 문장으로 만드는 것을 concatenation이라 하고, + 연산자를 쓴다.
예를 들어 name이라는 변수에 "Jimmy"가 들어 있을 때, print("Hello " + name + ", it's good to meet you!")라고 쓰면 화면에는 Hello Jimmy, it's good to meet you! 가 나온다.
주의할 점은 띄어쓰기(space)다. + 로 이을 때 문자열 안에 띄어쓰기를 적절한 자리에 넣어 두지 않으면 두 단어가 붙어 버린다. 그래서 "Hello"가 아니라 "Hello " 처럼 끝에 한 칸을 넣는다.

여러 과목 예제
자료의 예제 프로그램은 input문으로 과목별 등급을 하나씩 묻고, 그 답을 ict 같은 알맞은 이름의 변수에 각각 저장한 뒤, 마지막에 print문 여러 줄로 정리된 보고서 형태로 화면에 띄운다.
여기서도 print문 안에서 따옴표로 감싼 부분은 글자 그대로 나오고, 따옴표 없이 쓴 변수 이름은 그 안에 든 내용이 나온다. 만약 변수 ict에 따옴표를 붙이면 저장된 등급 대신 ict라는 글자가 그대로 나와 버린다.

✍️ 꼭 알아야 하는 것

  • print()는 따옴표 안의 글자를 그대로 띄우고, 따옴표가 없으면 그 이름의 변수(variable) 내용을 찾아 띄운다. 그 변수가 없으면 에러가 난다.
  • input()은 메시지를 보여주고 사용자가 칠 때까지 기다리며, 친 값을 남겨 두려면 변수 = input("...") 형태로 변수에 저장해야 한다.
  • 문자열과 변수를 한 문장으로 잇는 것은 concatenation이고 + 를 쓴다. 이때 문자열 안에 띄어쓰기를 직접 넣어야 단어가 붙지 않는다.

핵심 낱말
입력(Input) — 사용자로부터 컴퓨터로 보내지는 값이다.
변수(Variable) — 프로그램이 입력을 저장해 두는 자리다.
출력(Output) — 컴퓨터로부터 사용자에게 보내지는 값이다.

입력은 사용자 → 컴퓨터로 가는 값이고, 출력은 컴퓨터 → 사용자로 가는 값이라 방향이 서로 반대다.

변수는 입력을 담아 두는 자리이므로, 입력을 받으면 변수에 저장해야 나중에 쓸 수 있다.

이 수업에서는 문자열과 변수가 서로 다르다는 점, 그리고 둘을 이어 붙이는 연결(concatenate)을 다룬다.

지금까지 print()와 input() 명령이 화면에 글자를 보여 주는 방법을 봤다.

…화면에 문자열 Bob을 출력한다.

…Bob이라는 이름의 변수를 찾아 그 안에 든 내용을 출력한다. 그리고 그 변수가 없으면 프로그램은 오류를 출력한다.

따옴표로 감싼 Bob은 글자 그대로의 문자열이고, 따옴표 없는 Bob은 변수 이름으로 취급된다.

따옴표 없이 쓴 이름의 변수가 존재하지 않으면 프로그램은 오류를 낸다.

11쪽 · 문자열 이어붙이기(Concatenation)
Concatenation(이어붙이기)
파이썬에서 print()나 input() 문장 안에서 문자열과 변수를 이어 붙여 긴 문장을 만들려면 '+' 연산자를 쓸 수 있다.
위 예시에서 프로그램에는 name이라는 변수가 있고, 그 안에는 문자열 'Jimmy'가 들어 있다.
그 아래 print() 문장에서는 '+' 연산자로 문자열 "Hello "와 변수의 내용, 그리고 또 다른 문자열 ", it's good to meet you!"를 이어 붙여 "Hello Jimmy, it's good to meet you!"라는 문장을 만들었다.
'+' 연산자로 문장을 만들 때는 문자열 속 알맞은 자리에 띄어쓰기(공백)를 넣는 것을 잊지 말아야 한다. 그러지 않으면 두 낱말이 붙어 버릴 수 있다.

'+' 연산자는 문자열과 변수를 이어 붙여 한 문장으로 만드는 데 쓴다.

문자열 안에 공백을 넣지 않으면 낱말끼리 붙으므로, "Hello "처럼 알맞은 자리에 띄어쓰기를 넣어야 한다.

파이썬 print·input·변수·문자열 이어붙이기를 익히는 수업 자료다.

출력(output) — 파이썬에서 화면에 글자를 띄울 때는 print()를 쓴다.
print()는 괄호 안에 든 내용을 화면에 내보낸다.
글자(텍스트)를 그대로 띄우고 싶으면 반드시 따옴표(quotes)로 감싸야 한다. 예: print("Bob")은 화면에 Bob이라고 찍힌다.

입력(input) — 사용자에게 무언가를 물어보고 받아 적을 때는 input()을 쓴다.
input은 화면에 질문을 띄우고, 사용자가 키보드로 칠 때까지 기다린다.
print와 input의 가장 큰 차이가 바로 이것이다. print는 그냥 보여주고 끝나지만, input은 보여주고 멈춰서 기다린다.

변수(variable) — input으로 받은 값은 그냥 두면 사라진다. 그래서 저장할 곳이 필요하고, 그 저장 장소가 변수다.
변수는 컴퓨터 메모리 안의 저장 공간(memory location / storage area)이다.
저장하려면 input 문장이 변수와 등호(=)로 연결돼야 한다. 예: answer = input("질문") 이렇게 쓰면 사용자가 친 값이 answer라는 변수에 들어간다.
그 뒤에 print(answer)라고 쓰면 저장해 둔 값이 화면에 나온다.

문자열(string) — 프로그래밍에서 글자(텍스트)를 string이라고 부른다. 키보드로 칠 수 있는 여러 문자들로 이루어진 자료형(data type)이다.
변수는 이 string을 담을 수 있는 그릇이다.

따옴표가 있고 없고의 차이 — 이것이 이 수업에서 제일 헷갈리는 부분이다.
print("Bob")처럼 따옴표가 있으면 → Bob이라는 글자 그 자체가 나온다.
print(Bob)처럼 따옴표가 없으면 → 파이썬은 Bob이라는 이름의 변수를 찾는다. 그 변수에 들어있는 내용을 대신 띄운다.
그런데 Bob이라는 변수가 아예 없으면 프로그램은 에러(error)를 낸다.

이어붙이기(concatenation) — 글자와 변수를 붙여서 긴 문장 하나로 만들 때는 + 기호(operator)를 쓴다.
예를 들어 name이라는 변수에 "Jimmy"가 들어있다고 하자.
print("Hello " + name + ", it's good to meet you!") 라고 쓰면 화면에는 Hello Jimmy, it's good to meet you! 라고 한 문장으로 나온다.
★주의할 점 — 따옴표 안 글자에 띄어쓰기(space)를 알맞은 자리에 직접 넣어야 한다. 안 넣으면 두 단어가 HelloJimmy처럼 딱 붙어버린다.

실제로 짜 보는 프로그램 — 이 수업에서 만들어 보는 것은 세 가지다.
① 이름과 나이를 input으로 받아 각각 변수에 저장하고, 그 둘을 화면에 출력하는 프로그램.
② 이름을 받아서 인사말과 이어붙여 "Hello Joe" 형태로 출력하는 프로그램.
③ 여러 과목(subject)의 현재 등급(level)을 하나씩 물어보고, 과목마다 알맞은 이름의 서로 다른 변수에 저장한 뒤, 보기 좋게 정리된 성적표 형태로 출력하는 프로그램.
③번에서 중요한 것은 변수 이름을 ict처럼 내용을 알아볼 수 있게 짓는 것과, print 안에서 따옴표 친 설명 글과 따옴표 없는 변수를 섞어 쓰는 것이다. 변수 자리에 따옴표를 치면 안에 든 값이 아니라 ict라는 글자가 그대로 나와 버린다.

✍️ 꼭 알아야 하는 것

  • print와 input의 차이 — print는 메시지를 보여주기만 하고, input은 메시지를 보여준 뒤 사용자가 칠 때까지 기다린다. 그래서 input은 받은 값을 저장하려면 변수와 = 로 연결해야 한다.
  • 따옴표의 유무 — 따옴표가 있으면 그 글자(string) 그대로 출력되고, 따옴표가 없으면 그 이름의 변수(variable) 속 내용이 출력된다. 없는 변수 이름이면 에러가 난다.
  • + 로 string과 변수를 이어붙이는 concatenation, 그리고 띄어쓰기를 따옴표 안에 직접 넣어야 단어가 붙지 않는다는 점.

10쪽 · 문자열, 변수, 따옴표
프로그래밍에서 글자는 문자열(string)이라고 부른다.
문자열은 여러 키보드 문자로 이루어진 자료형(data type)이다.
변수는 문자열(글자)을 담을 수 있는 메모리 위치(저장 공간)다.
print()나 input() 문장에서 문자열을 출력하고 싶을 때는 반드시 따옴표를 써야 한다.
예를 들어 다음 코드는 화면에 문자열 Bob을 출력한다.
따옴표를 쓰지 않으면 파이썬은 그 이름을 가진 변수를 출력하려는 것으로 여긴다.
예를 들어 다음 코드는 Bob이라는 변수를 찾아 그 안에 든 내용을 출력한다.
그리고 그 변수가 없으면 프로그램은 오류를 출력한다.

문자열은 키보드 문자로 이루어진 자료형이고, 변수는 그 문자열을 담는 저장 공간이다.

print()나 input()에서 글자 그대로 출력하려면 따옴표를 쓰고, 따옴표를 빼면 같은 이름의 변수를 찾아 그 내용을 출력하며 변수가 없으면 오류가 난다.

11쪽 · 문자열 이어붙이기(Concatenation)
Concatenation(이어붙이기)
파이썬에서 print()나 input() 안에서 문자열과 변수를 이어 붙여 긴 문장을 만들려면 '+' 연산자를 쓸 수 있다.
위 그림에서 프로그램에는 name이라는 변수가 있고, 그 안에는 문자열 'Jimmy'가 들어 있다.
그 아래 print() 문에서는 '+' 연산자로 문자열 "Hello "와 변수의 내용, 그리고 또 다른 문자열 ", it's good to meet you!"를 이어 붙여 "Hello Jimmy, it's good to meet you!"라는 문장을 만들었다.
'+' 연산자로 문장을 만들 때는 문자열의 알맞은 자리에 띄어쓰기를 넣는 것을 잊지 말아야 한다. 그렇지 않으면 두 낱말이 붙어버릴 수 있다.

'+' 연산자로 문자열과 변수를 이어 붙여 한 문장을 만든다.

문자열 안 알맞은 위치에 띄어쓰기를 넣지 않으면 낱말끼리 붙어버린다.

파이썬 자료형(data type)과 int() 변환으로 계산하는 법을 배우는 자료다.

입력·변수·출력(input, variable, output) — input은 사용자가 컴퓨터로 보내는 값이다.
variable(변수)는 그 입력이 저장되는 자리다.
output은 컴퓨터가 사용자에게 내보내는 값이다.
파이썬에서 input 문은 사용자에게 값을 입력하라고 물어보고, 그 값을 변수에 저장한 뒤 print 문으로 다시 화면에 내보낼 수 있다.

print와 input의 차이 — print는 메시지를 화면에 보여주기만 한다.
input은 메시지를 보여준 다음 사용자가 입력할 때까지 기다린다.
그래서 사용자가 친 값을 저장하려면 input 문은 반드시 변수와 =로 연결되어야 한다. 예: answer = input(...)

자료형 세 가지(data types) — String(문자열)은 키보드로 칠 수 있는 글자·숫자·기호의 아무 조합이다.
Integer(정수)는 소수점이 없는 정수다. 컴퓨터가 어떤 값을 integer로 알고 있으면 그 값으로 계산(maths)을 할 수 있다.
Real(실수)은 소수점이 있는 소수·분수형 수다.

왜 컴퓨터에 자료형을 알려줘야 하나 — 컴퓨터는 값을 변수에 저장하는데, 그 입력을 이해하려면 그것이 어떤 종류의 데이터인지 알아야 한다.
변수에 단어를 담을 거면 그 변수가 string이라고 알려줘야 한다.
변수에 정수를 담고 계산을 시킬 거면 그 변수가 integer라고 알려줘야 한다.
이것을 하지 않으면 프로그램은 작동하지 않는다.

입력은 무조건 문자열로 들어온다 — num1 = input("please enter a number") 처럼 숫자를 입력받아도, 파이썬은 그 변수를 자동으로 string으로 설정한다.
파이썬은 그것을 숫자로 인식하지 않고 그냥 키보드 기호로 인식하기 때문이다.
그래서 입력받은 값으로 계산을 하려면 그 변수가 숫자(integer)를 담고 있다고 컴퓨터에 따로 알려줘야 한다.

자료형 바꾸기 — int() 함수 — 변수를 integer 자료형으로 변환(convert)하면 된다. 이때 쓰는 것이 int() 함수다.
num1, num2에 두 숫자를 입력받아 저장했다면, 파이썬은 이것을 string으로 저장했으므로 int()로 감싸 integer로 바꿔 준다.
자료에서는 이것을 'Mr Int.'라는 그림으로 설명한다. 변수 num1 안에 든 것이 'Twenty Nine(글자)'이 아니라 29(숫자)임을, 즉 이 변수는 단어가 아니라 숫자를 담고 있다는 것을 컴퓨터에게 알려 주는 역할이다.

변환한 뒤에야 계산이 된다 — num1에 'Five', num2에 'Nine'처럼 글자로 들어 있던 것이 int() 변환 뒤 5와 9라는 숫자가 된다.
그 다음 5 + 9를 해서 answer 변수에 14가 저장되고, 그 값을 출력할 수 있다.
즉 순서는 입력 → int()로 변환 → 계산(arithmetic) → 출력이다.

✍️ 꼭 알아야 하는 것

  • 파이썬에서 input()으로 받은 값은 숫자를 쳤더라도 항상 string이라는 것, 그래서 계산 전에 int()로 변환해야 한다는 것
  • String(글자·숫자·기호 조합), Integer(정수), Real(소수)의 뜻을 영어 용어 그대로 구분해 쓰는 것
  • print는 보여주기만 하고 input은 보여준 뒤 사용자 입력을 기다리므로 변수에 저장해야 한다는 차이

8쪽 · 자료형이란 무엇인가
자료형이란 무엇인가?
• 어떤 종류의 자료들이 있는가?
문자열(String)
키보드 문자(글자, 숫자, 기호)를 아무렇게나 조합한 것을 뜻한다.
정수(Integer)
모든 정수(소수점 없는 수)를 뜻한다. 컴퓨터가 그 자료를 정수로 알고 있으면 그 자료로 계산을 할 수 있다.
실수(Real)
모든 소수(분수 형태의 수)를 뜻한다.

문자열은 글자·숫자·기호를 아무렇게나 조합한 것이라, 그 안에 숫자가 들어 있어도 계산용 수가 아니다.

정수는 소수점이 없는 수이고 실수는 소수점이 있는 수이며, 컴퓨터가 정수로 인식해야 그 자료로 계산을 할 수 있다.

9쪽 · 변수의 자료형을 알려줘야 하는 까닭
컴퓨터는 값을 변수에 저장한다.
컴퓨터가 우리가 넣는 값을 이해하려면, 그 값이 어떤 자료형인지 알아야 한다.
변수에 낱말을 담으려면, 그 변수가 문자열을 담는다고 컴퓨터에 알려줘야 한다.
변수에 정수를 담으려면, 그 변수가 정수를 담는다고 알려줘야 한다 — 그래야 계산을 할 수 있다.
이것을 하지 않으면 프로그램이 작동하지 않는다.

컴퓨터는 변수에 담기는 값의 자료형을 알아야 입력을 이해한다.

낱말은 문자열, 정수는 정수로 알려줘야 하고 정수라고 알려줘야 계산이 된다. 알려주지 않으면 프로그램이 돌아가지 않는다.

10쪽 · 숫자 계산하기
계산하기 (Doing Arithmetic)
프로그램이 숫자를 다루게 하려면, 어떤 변수가 숫자를 담을 것이라고 프로그램에 알려 주어야 한다.
프로그램에 숫자를 입력할 때…
num1 = input("please enter a number")
…파이썬은 그 변수를 자동으로 문자열(string)로 정한다. (숫자로 알아보지 못하고, 그저 키보드 기호로만 알아본다.)
입력받은 값으로 계산을 하려면, 그 변수가 숫자(정수, integer)를 담고 있다고 컴퓨터에 알려 주어야 한다.

input()으로 받은 값은 파이썬이 무조건 문자열로 저장한다 — 숫자로 보지 않는다.

계산을 하려면 그 변수가 정수(integer)라고 컴퓨터에 알려 줘야 한다.

11쪽 · 자료형 바꾸기 — int()
자료형 바꾸기
위에서 두 개의 숫자가 입력되어 num1과 num2라는 변수에 저장된 것을 볼 수 있다.
파이썬은 입력을 문자열(string)로 저장하기 때문에 이 변수들을 정수(integer)로 바꿔야 한다.
그렇게 하려면 변수를 '정수(integer)' 자료형으로 변환해야 한다.
int() 함수가 이것을 할 수 있게 해 준다!

파이썬은 input()으로 받은 값을 문자열로 저장하므로, 숫자로 쓰려면 변환해야 한다.

int() 함수를 쓰면 변수를 정수 자료형으로 바꿀 수 있다.

파이썬(Python) — 파이썬은 사람이 쓴 글에 가까운 프로그래밍 언어(programming language)다.
적어 놓은 줄을 위에서 아래로 한 줄씩 차례대로 실행한다.
Exercise 1은 코드를 직접 쳐서 결과를 확인하는 실습이므로, 눈으로 읽기만 하지 말고 실제로 입력해서 돌려 봐야 한다.

출력 print() — 화면에 무언가를 보여 주려면 print()를 쓴다.
글자를 그대로 보여 줄 때는 반드시 따옴표(quotation marks)로 감싼다. 예: print("Hello")
따옴표 없이 쓰면 파이썬은 그것을 글자가 아니라 이름으로 착각한다.
숫자는 따옴표 없이 쓴다. print(3+4)는 7을 보여 주지만 print("3+4")는 3+4라는 글자를 그대로 보여 준다.

변수(variable)와 대입(assignment) — 값을 상자에 담아 이름을 붙여 두는 것이 변수다.
예: name = "Seojeong", age = 15
여기서 =은 '같다'가 아니라 '오른쪽 값을 왼쪽 이름에 넣어라'는 뜻이다. 이것을 대입이라고 한다.
같은 이름에 새 값을 넣으면 예전 값은 사라지고 마지막 값만 남는다.
변수 이름은 띄어쓰기를 못 쓰고 숫자로 시작할 수 없으며, 대문자와 소문자를 다른 글자로 구분한다(Name과 name은 다른 변수다).

자료형(data type) — 값의 종류다.
정수(int)는 3, 10처럼 소수점이 없는 수다.
실수(float)는 3.5처럼 소수점이 있는 수다.
문자열(string, str)은 따옴표로 감싼 글자다.
불리언(boolean, bool)은 True 또는 False 둘 중 하나다. True와 False는 첫 글자가 대문자다.
종류가 다르면 다루는 방법도 달라진다. "5"는 숫자처럼 보여도 글자다.

입력 input() — 사용자에게 무언가를 물어볼 때 쓴다. 예: name = input("What is your name? ")
여기서 꼭 기억할 점은 input()이 받아 온 값은 언제나 문자열(string)이라는 것이다.
그래서 나이나 개수처럼 계산에 쓸 값은 int()나 float()로 바꿔 줘야 한다. 예: age = int(input("Your age: "))
바꾸지 않고 계산하면 글자끼리 붙어 버리거나 오류가 난다.

연산자(operator) — 더하기 +, 빼기 -, 곱하기 *, 나누기 /를 쓴다.
나누기 /의 결과는 언제나 소수(float)가 된다. 10/2는 5가 아니라 5.0이다.
몫만 필요하면 //, 나머지는 %, 거듭제곱은 **를 쓴다.
문자열에 +를 쓰면 더하는 것이 아니라 글자를 이어 붙인다. "Hello" + "Kim"은 HelloKim이 된다.
숫자와 문자열을 +로 섞으면 오류가 나므로 str()로 숫자를 글자로 바꾸거나 print에서 쉼표로 나눠 쓴다.

문법(syntax)과 오류(error) — 파이썬은 철자와 기호에 아주 엄격하다.
괄호를 닫지 않거나 따옴표 한쪽을 빠뜨리면 SyntaxError가 난다.
만들지 않은 변수를 쓰거나 이름 철자를 틀리면 NameError가 난다.
글자에 숫자 계산을 하려 하면 TypeError가 난다.
오류 메시지에는 몇 번째 줄이 문제인지 줄 번호가 적혀 나오니, 겁먹지 말고 그 줄부터 다시 본다.
주석(comment)은 # 뒤에 쓰며, 그 줄은 실행되지 않는다. 코드가 무슨 뜻인지 스스로 적어 두는 자리다.

알고리즘과 순서도(flowchart)의 기초를 배우는 9학년 컴퓨팅 수업 자료다.

이 수업의 큰 질문(Big Question)은 어떻게 하면 컴퓨터가 문제를 제대로 풀도록 명확한 단계를 계획할 수 있는가이다. 컴퓨터는 사람처럼 알아서 눈치껏 해주지 않고, 시킨 대로 정확히(exactly) 그대로만 따라간다. 그래서 코드를 쓰기 전에 계획을 먼저 세워야 실수를 줄이고 결과를 검사(test)할 수 있다는 것이 이 자료가 계속 말하는 이유다.

자료 맨 앞에 나오는 흐름은 계획(Plan) → 그림(Diagram) → 코드(Code) → 검사(Test)다. 즉 머릿속 생각을 먼저 알고리즘(algorithm), 곧 문제를 푸는 단계별 순서로 적고, 그 다음 그 순서를 그림으로 그린 것이 순서도(flowchart)이며, 코딩은 그 뒤에 온다. 순서를 거꾸로 해서 바로 코드부터 쓰는 것이 아니라는 점이 핵심이다.

순서도에 쓰이는 기호들도 자료에 그림으로 나와 있다. START(시작), INPUT(값을 넣음), PROCESS(계산·처리), DECIDE(판단), OUTPUT(결과를 내보냄)이며, 이 중 DECIDE는 마름모(diamond) 모양이라 다른 상자들과 생김새가 다르다. 모양이 곧 그 칸이 하는 일을 뜻하므로, 모양과 뜻을 짝지어 외워 두는 것이 좋다.

수업이 끝났을 때 할 수 있어야 하는 것(Learning Outcomes)은 세 가지로 적혀 있다. 첫째 알고리즘이 무엇이고 왜 쓰는지 설명하기, 둘째 주요 순서도 기호와 그 뜻을 구분하기, 셋째 간단한 계산 문제에 대해 알고리즘을 쓰고 순서도를 그리기다. 결국 이 수업의 목표 결과물은 '간단한 계산을 하는 알고리즘 한 개 + 그것을 옳게 그린 순서도 한 장'이다.

✍️ 꼭 알아야 하는 것

  • 순서도 기호 다섯 가지 — START(시작), INPUT(입력), PROCESS(처리), DECIDE(판단, 마름모 모양), OUTPUT(출력) — 의 이름과 뜻을 각각 알아야 한다.
  • 알고리즘은 문제를 푸는 명확한 단계이고, 순서도는 그 단계를 그림으로 나타낸 것이며, 코드를 쓰기 전에 Plan → Diagram → Code → Test 순서로 계획한다는 흐름을 설명할 수 있어야 한다.

순서도 기호 네 가지(입력·처리·출력·판단)는 영어 이름과 모양을 함께 외워 둔다. 시험에서 기호를 고르거나 직접 그리는 문제가 자주 나온다.

문제에서 프로그램까지(From Problem to Program)
컴퓨터로 문제를 푸는 간단한 과정이다.

① 문제 분석하기(Analyse the problem) → ② 알고리즘 쓰기(Write an algorithm) → ③ 순서도 그리기(Draw a flowchart) → ④ 프로그램으로 바꾸기(Convert to program) → ⑤ 해결책 실행하고 시험하기(Run & test the solution)

좋은 프로그래머는 곧바로 코딩(coding)부터 시작하지 않는다. 먼저 문제를 이해하고, 단계를 설계한 다음, 결과를 시험(test)한다.

다섯 단계의 순서를 영어로 외워 두어야 한다. 코드를 쓰기 전에 알고리즘과 순서도로 먼저 설계한다는 점이 핵심이다.

알고리즘(Algorithm)이란 무엇인가?
알고리즘은 특정한 문제(specific problem)를 풀기 위한 명확하고 순서가 정해진 단계들(clear, ordered steps)의 모음이다.

알고리즘 체크리스트(Algorithm Checklist)
✓ 시작이 분명하다(Starts clearly)
✓ 순서가 정해진 단계(ordered steps)를 사용한다
✓ 정확한 지시(exact instructions)를 사용한다
✓ 답(결과)을 만들어 낸다(Produces an answer)
✓ 시험해 볼 수 있다(Can be tested)

예시: 샌드위치 만들기(Make a sandwich)
1. 빵을 가져온다(Get bread)
2. 속재료를 넣는다(Add filling)
3. 샌드위치를 덮는다(Close sandwich)
4. 내놓는다(Serve)

컴퓨팅(computing)에서는 각 단계가 정확해야(precise) 한다. 컴퓨터는 우리가 무슨 뜻으로 말했는지 짐작할 수 없기(cannot guess) 때문이다.

알고리즘의 정의 'a set of clear, ordered steps to solve a specific problem'은 시험에 그대로 나오기 쉬우니 영어 문장째 외워 두면 좋다. 순서(order)를 바꾸면 결과가 달라진다는 점도 함께 기억한다.

차 한 잔은 어떻게 만들까?
학생들이 순서(instructions)를 말해 보게 한다:
1. 물을 끓인다.
2. 컵에 티백을 넣는다.
3. 뜨거운 물을 붓는다.
4. 우유를 넣는다.
5. 설탕을 넣는다.
6. 젓는다.
그다음 설명한다:
알고리즘(algorithm)은 문제를 풀거나(solve a problem) 일을 끝내기(complete a task) 위해 쓰는 단계별(step-by-step) 명령(instructions)의 모음이다.
이렇게 하면 개념이 덜 추상적(less abstract)이 된다.

알고리즘의 정의 'a step-by-step set of instructions used to solve a problem or complete a task'는 시험에 그대로 나오기 쉬우니 영어 문장째 외워 둔다. 차 만들기처럼 순서가 바뀌면 결과가 달라지므로, 알고리즘에서는 단계의 순서가 중요하다.

순서도(Flowchart)란 무엇인가?
순서도(flowchart)는 문제를 푸는 단계(steps)를 그림으로 보여 주는 시각적 도표(visual diagram)다.

[도표] 시작(START) → 입력(INPUT) → 처리(PROCESS) → 판단(DECISION)(마름모 모양) → 출력(OUTPUT) → 끝(END)

순서도를 쓰면 코드를 짜기 전에 논리(logic)를 읽고, 함께 이야기하고, 오류를 찾아 고치기(debug)가 더 쉬워진다.

도형마다 뜻이 정해져 있다. 시작·끝은 둥근 사각형, 판단(decision)은 마름모이고, 판단에서는 예(Yes)/아니오(No)에 따라 길이 갈린다.

자주 쓰는 순서도 기호(Common Flowchart Symbols)
그 단계가 무슨 일을 하는지에 따라 기호를 고른다.

시작 / 끝(Start / End)
타원 모양(Oval shape)
단말 기호(Terminator)

입력 / 출력(Input / Output)
평행사변형(Parallelogram)
데이터를 읽거나 출력한다(Read or print data)

처리(Process)
직사각형(Rectangle)
계산하거나 저장한다(Calculate or store)

판단(Decision)
마름모(Diamond)
질문: 예/아니요(Question: yes/no)

흐름선(Flow Line)
화살표(Arrow)
방향을 보여 준다(Shows direction)

연결자(Connector)
원(Circle)
부분들을 이어 준다(Connects parts)

시험에는 기호 모양과 하는 일을 짝지어 묻는 문제가 자주 나온다. 입력·출력은 평행사변형, 판단은 마름모인데 판단에서는 화살표가 Yes와 No 두 갈래로 나뉜다는 점을 함께 기억한다.

순서도 기호표
모양(Shape) | 하는 일(Operation)
① 양 끝이 둥근 직사각형 — 시작 또는 끝(Start or End)
② 평행사변형 — 데이터 입력/출력(Input / Output data): 읽기 또는 입력(Read or Input), 출력(Print)
③ 직사각형 — 처리/저장(Processing / Storing): 더하기(Add, +), 빼기(Sub, -), 곱하기(Mul, *), 나누기(Div, /), 거듭제곱(Power, ^) 등, 값 저장하기(Store a value, Put)
④ 위·아래·오른쪽·왼쪽 화살표 — 흐름선(Flow Lines)
⑤ 원 — 연결(Connection)
⑥ 마름모 — 판단(Decision): If 문(If statement), 질문(Question, ?)
⑦ 육각형 — 반복/카운터(Looping / Counters)
⑧ 양옆에 세로줄이 있는 직사각형 — 서브루틴(Subroutine)

시험에는 모양과 이름을 짝짓는 문제가 자주 나온다. 특히 입력·출력은 평행사변형(parallelogram), 판단은 마름모(diamond), 처리는 직사각형(rectangle)이라는 것을 꼭 외워 둔다.

풀이 예제(Worked Example): 두 수 더하기
간단한 계산을 위한 알고리즘(algorithm)과 순서도(flowchart)이다.

알고리즘(Algorithm)
1. 시작(Start)
2. a, b를 입력받는다(Read a, b)
3. sum = a + b (합계를 계산한다)
4. sum을 출력한다(Print sum)
5. 끝(End)

순서도(Flowchart) — 위에서 아래로 화살표를 따라간다.
• 둥근 사각형 Start(시작)
• 평행사변형 Read a.b — a, b 입력
• 직사각형 sum=a+b — 계산(처리)
• 평행사변형 Print sum — sum 출력
• 둥근 사각형 Stop(끝)

순서도 도형마다 뜻이 다르다. 둥근 사각형은 시작/끝(terminator), 평행사변형은 입력/출력(input/output), 직사각형은 처리(process)이다. 알고리즘의 각 단계가 순서도의 도형 하나씩과 짝을 이룬다.

예제 1(Example-1)
다섯 개의 수를 입력받아 그 합(sum)과 평균(average)을 구하는 알고리즘(algorithm)을 쓰고 순서도(flow chart)를 그려라. 결과를 출력하라.

풀이(Solution):
1. 시작(Start)
2. L, M, N, O, P를 입력받는다(Read)
3. 합(A)을 구한다(Find Sum), A = L+M+N+O+P
4. 평균(B)을 구한다(Find Average), B = A / 5
5. A, B를 출력한다(Print)
6. 끝(End)

순서도(flow chart): 위에서 아래로 화살표로 이어진다.
둥근 모서리 칸 'Start(시작)' → 평행사변형 'Read L,M,N,O,P(입력)' → 직사각형 'A=L+M+N+O+P' → 직사각형 'B=A/5' → 평행사변형 'Print A,B(출력)' → 둥근 모서리 칸 'End(끝)'

순서도에서 도형마다 뜻이 정해져 있다. 둥근 모서리 칸은 시작/끝(terminator), 평행사변형은 입력/출력(input/output), 직사각형은 계산 같은 처리(process)다. 평균은 합을 먼저 구한 뒤 개수(5)로 나누므로 3번과 4번의 순서가 바뀌면 안 된다.

나머지 약속은 컴퓨터 수업이라서 특히 강조되는 것들이다. 창의(Innovation)는 실수에서 배우며 새 방법을 시도하는 것, 안전(Safety)은 장비와 프로그램을 규칙대로 쓰고 개인정보를 지키는 것이다. 디지털 시민의식(Digital Citizenship)은 인터넷에 남는 흔적, 즉 디지털 발자국(digital footprint)을 생각하며 쓰라는 뜻이다. 성장 마인드셋(Growth Mindset)은 지적(feedback)을 받아들이고 계속 실력을 키우려는 태도다.

일 년 동안 배울 주제는 학기별로 나뉜다. 1학기(Term 1)는 알고리즘과 순서도(Algorithm and Flowcharts), 파이썬 프로그래밍(Python Programming)이다. 2학기(Term 2)는 스프레드시트와 알고리즘적 사고(Spreadsheets and Algorithmic Thinking), 3학기(Term 3)는 데이터베이스(Databases)와 컴퓨터 네트워크(Computer Networks)다. 평가는 CA-Project, 즉 과제·프로젝트로 하는 평가라고 적혀 있다.

Question 1 of 10 3 marks
State what an algorithm is and give two rules that the steps of an algorithm must follow.
알고리즘의 정의와 지켜야 할 규칙(명확성·종료)을 묻는 문제.

Model answer

An algorithm is a set of ordered steps used to solve a problem. Each step must be unambiguous, so there is no confusion about what to do. The algorithm must also terminate (eventually stop), and the same input must always produce the same result.

Question 2 of 10 4 marks
Describe the meaning of each of these flowchart symbols: oval, parallelogram, rectangle and diamond.
순서도 기호 네 가지의 뜻을 각각 설명하는 문제.

Model answer

An oval is the terminator and shows Start or Stop/End. A parallelogram is used for input or output, such as INPUT or PRINT. A rectangle is a process, such as a calculation or storing a value (for example total = total + 1). A diamond is a decision, which asks a condition and has two exits labelled Yes and No.

Question 3 of 10 4 marks
Explain the difference between selection and iteration in a flowchart, and describe how you can tell that a flowchart contains a loop.
선택과 반복의 차이, 그리고 순서도에서 반복을 알아보는 방법(되돌아가는 화살표)을 묻는 문제.

Model answer

Selection uses a diamond to ask a condition and the flow splits into two branches (Yes and No); in code this is IF … THEN … ELSE. Iteration means part of the flowchart is repeated. You can tell a loop is present because an arrow goes back up to an earlier step; if there is no arrow going back, it is not a loop. A loop that repeats while a condition is true is a WHILE loop, and one that repeats a fixed number of times is a FOR loop.

Question 4 of 10 3 marks
A student writes a flowchart that adds up numbers using a variable called total, but forgets to set total = 0 before the loop. Explain what initialisation is and why leaving it out is a problem.
초기화의 뜻과 빠뜨렸을 때 생기는 문제를 설명하는 문제.

Model answer

Initialisation means giving a variable a starting value before a loop begins, such as total = 0 or count = 0. If total is not initialised, it does not have a known starting value, so the running total will be wrong. This is why flowchart fill-in-the-blank questions often ask for the initialisation box.

Question 5 of 10 3 marks
Explain the difference between a counter and a running total, giving the process line that would be written inside a rectangle for each.
카운터와 합계(누적) 변수의 차이와 각각의 처리식을 쓰는 문제.

Model answer

A counter is a variable that records how many times something has happened and goes up by 1 each time, written as count = count + 1. A running total is a variable that keeps adding values together to build up a sum, written as total = total + number. Both are process steps, so both are written inside a rectangle in a flowchart.

Question 6 of 10 3 marks
Explain what a trace table is and describe how you should fill one in for a flowchart.
추적표의 뜻과 올바르게 채우는 방법을 묻는 문제.

Model answer

A trace table is a table used to follow a flowchart one step at a time and record how the values of the variables change. Each variable has its own column, and a new row is written every time a value changes. There is a separate OUTPUT column, and only values that are actually printed on the screen are written there. You should write each step down rather than working it out in your head, because writing it down is more accurate.

Question 7 of 10 3 marks
State the main difference between the print() and input() commands in Python, and explain why an input statement must be joined to a variable with an equals sign.
print와 input의 차이, 그리고 input을 변수에 '='로 연결해야 하는 이유를 묻는 문제.

Model answer

print() just displays a message on the screen and then carries on. input() displays a message and then waits for the user to type something in. The value the user types must be stored somewhere, and that storage space in memory is a variable, so the input statement must be connected to a variable with '=' (for example answer = input("...")). The stored value can then be shown again later with print(answer).

Question 8 of 10 3 marks
Explain the difference between writing print("Bob") and print(Bob) in Python.
따옴표가 있을 때와 없을 때 print가 어떻게 달라지는지 설명하는 문제.

Model answer

print("Bob") has quotation marks, so Python displays the text Bob exactly as it is written. print(Bob) has no quotation marks, so Python looks for a variable called Bob and tries to display the contents stored inside it. If no variable called Bob has been created, the program produces an error (a NameError).

Question 9 of 10 4 marks
A variable called name contains "Jimmy". Explain what concatenation is, and explain why the programmer must be careful about spaces when writing print("Hello " + name + ", it's good to meet you!").
이어붙이기(concatenation)의 뜻과 띄어쓰기를 직접 넣어야 하는 이유를 묻는 문제.

Model answer

Concatenation means joining strings and variables together into one sentence, and in Python it is done with the + operator. In this example the output is Hello Jimmy, it's good to meet you! because the contents of the variable are joined to the text in quotes. The programmer must put the spaces inside the quotation marks themselves, for example "Hello " with a space at the end. If the space is missing the two words are joined together and the output would read HelloJimmy.

Question 10 of 10 4 marks
A student writes num1 = input("please enter a number") and num2 = input("please enter a number") and then tries to add them. Explain why this does not give the correct calculation and describe how int() fixes it.
입력값이 항상 문자열이라 계산이 안 되는 이유와 int() 변환의 역할을 묻는 문제.

Model answer

Anything entered with input() is automatically stored as a string, because Python treats what is typed as keyboard characters and not as numbers. Before a calculation can be done, the computer must be told that the variable holds an integer, and this is done by converting the variable with the int() function. Once num1 and num2 have been converted with int(), the values become the numbers 5 and 9 rather than words, so 5 + 9 can be worked out and 14 stored in the answer variable. The correct order is input → convert with int() → calculate → output.
