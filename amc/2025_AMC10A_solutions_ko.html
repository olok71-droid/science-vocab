1번 답 E (4시 30분)
앤디가 출발하고 t시간 뒤를 보면 앤디는 8t, 베치는 한 시간 늦게 떠났으니 12(t−1)만큼 갔다. 두 거리가 같아지는 때이므로 8t = 12t − 12 → t = 3. 1시 30분에서 3시간 뒤 = 4시 30분.
2번 답 B (4파운드)
처음 10파운드에는 땅콩 5, 캐슈 2, 아몬드 3파운드가 있다. 두 번째 믹스를 x파운드 부으면 땅콩은 5 + 0.2x, 전체는 10 + x. 땅콩이 40%가 되므로 5 + 0.2x = 0.4(10 + x) → x = 5. 캐슈는 2 + 0.4 × 5 = 4파운드.
3번 답 D (3037개)
두 경우로 나눈다. ① 같은 두 변이 2025인 경우: 밑변은 1부터 2025까지 → 2025개. ② 밑변이 2025인 경우: 같은 두 변 a는 2a > 2025라야 하므로 1013부터 2024까지 → 1012개. 합하면 3037개.
4번 답 A (28살)
학생 s명, 교사 t명, s + t = 15. 애쉬 나이를 A라 하면 학생 쪽은 (12s + A)/(s+1) = 14 → A = 2s + 14, 교사 쪽은 (55t + A)/(t+1) = 52 → A = 52 − 3t. 두 식을 s = 15 − t로 이어 풀면 t = 8, s = 7, A = 28.
5번 답 E (45)
수열은 덩어리로 끊어진다. n번째 덩어리는 1부터 n+1까지 올라갔다가 2까지 내려오며 길이가 2n이다. n번째 덩어리까지의 총 개수는 n(n+1)이므로 44번째까지 1980개, 45번째 덩어리에서 2025 − 1980 = 45번째 수다. 그 덩어리는 46까지 올라가므로 45번째 수는 올라가는 도중의 45.
6번 답 C (100°)
정삼각형의 60°가 20°씩 셋으로 나뉜다. 만들어지는 육각형은 100°와 140°가 번갈아 놓이는 모양이고, 세 개씩 더하면 3×100 + 3×140 = 720°로 육각형 내각의 합과 맞는다. 가장 작은 각은 100°.
7번 답 E (18)
나머지정리를 두 번 쓴다. f(1) = 1 + 1 + a + b = 4 → a + b = 2. f(2) = 8 + 4 + 2a + b = 6 → 2a + b = −6. 빼면 a = −8, b = 10 → b − a = 18.
8번 답 B (1개)
참인 문장 수를 T라 하자. 첫째는 T ≥ 1, 둘째는 T ≥ 2, 셋째는 거짓이 2개 이상 즉 T ≤ 2, 넷째는 T ≤ 3일 때 참이다. T = 3을 넣으면 참·참·거짓·참으로 참이 정확히 3개라 앞뒤가 맞는다. 다른 값은 모순이 난다. 따라서 거짓은 1개.
9번 답 C (3개)
조건은 f(1 − a) = 25 이므로, f(u) = 25가 되는 실수 u의 개수를 세면 된다. f(u) = 100u(u−1)(u−2)는 극대값이 약 38.5, 극소값이 약 −38.5라 y = 25인 가로선과 세 번 만난다.
10번 답 C (32π)
큰 반원 반지름을 R, 잘라낸 작은 반원 반지름을 r라 하면 색칠된 넓이는 (π/2)(R² − r²)이다. 작은 반원이 현에 접하므로 r는 지름에서 현까지의 거리와 같고, 현의 절반이 8이므로 R² − r² = 8² = 64. 따라서 넓이는 32π.
11번 답 E (149)
등차 쪽은 1, 1+d, 1+2d, 1+3d. 등비 쪽은 첫 항이 1인 정수 수열이라 공비가 정수 r이고 z = r³. r³ = 1 + 3d를 만족하려면 r를 3으로 나눈 나머지가 1이어야 하니 가장 작은 것은 r = 4, z = 64, d = 21. 그러면 22 + 43 + 64 + 4 + 16 = 149.
12번 답 D (464가지)
0이 없으니 숫자는 1~9다. 짝수만인 것 {4,6,8}, 소수만인 것 {3,5,7}, 둘 다인 것 {2}, 둘 다 아닌 것 {1,9}로 나눈다. ① 2를 한 번 써서 짝수·소수를 동시에 채우는 경우: 자리 4가지 × 나머지 세 자리 2³ = 32. ② 짝수 하나와 소수 하나를 따로 쓰는 경우: 자리 4×3 = 12, 숫자 3×3 = 9, 나머지 두 자리 2² = 4 → 432. 합 464.
13번 답 D (3/4)
색칠된 넓이는 (1 − k²)(1 + k⁴ + k⁸ + …) = (1 − k²)/(1 − k⁴) = 1/(1 + k²)이다. 이것이 0.64이므로 1 + k² = 1.5625 → k² = 0.5625 → k = 3/4.
14번 답 B (1/5)
여섯 자리에 네 사람을 앉히는 경우는 6×5×4×3 = 360가지. 학생 두 명이 붙어 앉는 자리 쌍은 6가지이고, 그때 남은 네 자리에서 교사가 붙어 앉을 쌍은 3가지다. 사람 순서까지 세면 6×3×2×2 = 72. 72/360 = 1/5.
15번 답 A (3/8)
그림(직사각형과 수직 조건)이 있어야 풀리는 문제다. 제가 그림 없이 풀어 쓰지는 않았고, 정답만 공식 정답표에서 확인했다.
16번 답 D (17/9)
동전 3개를 항아리 3개에 넣는 경우는 27가지. 셋이 한 항아리(3가지)면 최대 3개, 셋이 다 다른 항아리(6가지)면 최대 1개, 나머지 18가지는 최대 2개다. 기댓값은 (3×3 + 18×2 + 6×1)/27 = 51/27 = 17/9.
17번 답 E (4)
나머지를 뺀 273420과 272745가 모두 N의 배수여야 한다. 두 수의 최대공약수는 45이고, 나머지가 16·15였으니 N은 16보다 커야 한다. 45의 약수 중 16보다 큰 것은 45뿐이므로 N = 45, 십의 자리는 4.
18번 답 B (−3/2)
각 이차식 kx² − 4x − 3의 두 근에 대해 역수의 합은 (4/k) ÷ (−3/k) = −4/3으로 k와 무관하다. 근은 모두 4050개이고 역수의 총합은 2025 × (−4/3) = −2700이므로 조화평균은 4050 ÷ (−2700) = −3/2.
19번 답 A (−29)
줄마다 이웃끼리 더해 내려가는 배열 그림 문제다. 제가 손으로 줄을 끝까지 따라가 검산하지 않았고, 정답만 공식 정답표에서 확인했다.
20번 답 A (119)
원기둥에 접하는 시선 문제로, 원문에 좌표 수치가 그림과 함께 주어진다. 제가 수치를 원문 그대로 확인하지 못해 풀이는 쓰지 않았다. 정답만 공식 정답표에서 확인했다.
21번 답 C (10개)
11부터 20까지 열 개를 고르면 어떤 두 수를 더해도 22 이상이라 20을 넘어가므로 조건을 만족한다. 1부터 n까지에서는 큰 쪽 절반이 한계라 11개 이상은 만들 수 없다.
22번 답 B (6/23)
서로 외접하는 네 원에는 데카르트의 원 정리 (∑1/r)² = 2∑(1/r²)가 성립한다. 반지름 1, 2, 3과 구하는 r를 넣고 풀면 r = 6/23이 나온다.
23번 답 D (21)
A(0,0), B(80,0)으로 두면 AC = 75, BC = 45에서 C는 (62.5, √1718.75)이다. AB에 내린 수선은 x = 62.5인 세로선이고, B에서 그은 각의 이등분선을 이 선과 만나게 하면 교점은 (62.5, 11.608…)이 된다. B와의 거리는 정확히 21이다.
24번 답 C (9,841)
자릿수 배열을 조건에 맞게 세는 문제다. 제가 끝까지 세어 검산하지 않았고, 정답만 공식 정답표에서 확인했다.
25번 답 A (25)
정사각형 안 임의의 점에 대한 확률 문제로, 답은 a+b+c+d+e 형태로 묻는다. 제가 적분 구간을 직접 따져 검산하지 않았고, 정답만 공식 정답표에서 확인했다.
