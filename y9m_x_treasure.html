EEntry Task – Crack the Captain's Code선장의 암호 풀기
Solve the following five questions and use the answer bank to reveal the secret word.
1. Find 15% of 240.
풀이
답: 36 → S ① 백분율 percentage 15% = 15/100 = 0.15
② 0.15 × 240 = 36
③ 다른 방법: 10% = 24, 5% = 12 → 24 + 12 = 36
④ Answer bank 에서 36 = S
2. Solve 3x + 7 = 31.
풀이
답: x = 8 → T ① 양변에서 7 을 뺀다: 3x = 24
② 양변을 3 으로 나눈다: x = 8
③ 확인 check: 3 × 8 + 7 = 24 + 7 = 31 ✓
④ Answer bank 에서 8 = T (24 는 3x 의 값이라 함정 decoy 이다)
3. Calculate 3⁄4 + 5⁄8.
풀이
답: 13⁄8 → A ① 분모 denominator 를 같게 만든다 — 4 와 8 의 최소공배수 lowest common multiple = 8
② 3/4 = 6/8
③ 6/8 + 5/8 = 11/8
④ 가분수 improper fraction 11/8 을 대분수 mixed number 로: 11 ÷ 8 = 1 나머지 3 → 1 3/8
⑤ Answer bank 에서 1⅜ = A
4. Find the next term: 3, 7, 13, 21, …
풀이
답: 31 → R ① 이웃한 항 term 의 차이 difference 를 본다: 7 − 3 = 4, 13 − 7 = 6, 21 − 13 = 8
② 차이가 4, 6, 8 로 2 씩 커진다 (두 번째 차이 second difference = 2)
③ 다음 차이 = 10 → 21 + 10 = 31
④ 확인 check: n번째 항 nth term = n² + n + 1 → n = 5 일 때 25 + 5 + 1 = 31 ✓
⑤ Answer bank 에서 31 = R (29 는 21 + 8 로 잘못 더했을 때 나오는 함정)
5. Find y when y = 3x − 2 and x = 5.
풀이
답: y = 13 → T ① 대입 substitute: x 자리에 5 를 넣는다
② y = 3 × 5 − 2 = 15 − 2 = 13
③ Answer bank 에서 13 = T
Secret word: arrange the letters in question order (1 → 5).
풀이
답: START ① 1번 S, 2번 T, 3번 A, 4번 R, 5번 T
② 문제 순서대로 늘어놓으면 S T A R T → START
③ 선생님 답 Teacher's answer: START ✓
④ Answer bank 의 24(R), 12(E), 29(O) 는 쓰이지 않는 함정 decoy answers 이다
