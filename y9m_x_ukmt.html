Q1.
다음 중 값이 가장 큰 것은?
정답: E
클로드 설명풀이
  1. 분자 1 + 2 + … + n 은 n(n+1)/2 이다. 이것을 n 으로 나누면 (n+1)/2 가 된다.
  2. 그래서 각 보기의 값은 A = 3/2 = 1.5, B = 2, C = 5/2 = 2.5, D = 3, E = 7/2 = 3.5 이다.
  3. n 이 클수록 값이 커지므로 가장 큰 것은 E (3.5) 이다.
기억할 점: 평균(mean) 생각: 1부터 n까지의 평균은 가운데 값 (n+1)/2 이다.
Q2.
월요일 20:26 에서 2026분 뒤는 몇 시인가?
정답: D (수요일 06:12)
클로드 설명풀이
  1. 분을 시간으로 바꾼다: 2026 ÷ 60 = 33 나머지 46 → 33시간 46분.
  2. 33시간 = 24시간(하루) + 9시간 → 1일 9시간 46분.
  3. 월요일 20:26 + 1일 = 화요일 20:26.
  4. 화요일 20:26 + 9시간 = 수요일 05:26.
  5. 05:26 + 46분 = 06:12 → 수요일 06:12.
기억할 점: 큰 분(minutes)은 먼저 '일·시간·분'으로 쪼갠 다음 차례로 더한다.
Q3.
직육면체(cuboid)의 세 변의 길이(cm)가 연속하는 세 자연수이고 부피는 120 cm³ 이다. 가장 큰 면의 넓이(cm²)는?
정답: D (30)
클로드 설명풀이
  1. 연속하는 세 수를 n−1, n, n+1 이라고 둔다(consecutive = 연속하는).
  2. 부피 = (n−1) × n × (n+1) = 120.
  3. 작은 수부터 넣어 본다: 3×4×5 = 60 (작다), 4×5×6 = 120 (맞다!).
  4. 변의 길이는 4, 5, 6 cm. 가장 큰 면은 큰 두 변으로 만든 면이므로 5 × 6 = 30 cm².
기억할 점: 경시대회에서는 식을 다 풀기보다 '넣어 보기(trial)'가 빠를 때가 많다.
Q4.
35 를 1 : ½ : ¼ 의 비로 나눌 때 가장 작은 몫은?
정답: E (5)
클로드 설명풀이
  1. 분수 비는 모두 4를 곱해 자연수 비로 바꾼다: 1 : ½ : ¼ = 4 : 2 : 1.
  2. 전체 칸 수 = 4 + 2 + 1 = 7.
  3. 한 칸 = 35 ÷ 7 = 5.
  4. 가장 작은 몫은 1칸 → 5.
기억할 점: 비(ratio)에 분수가 있으면 분모의 최소공배수를 곱해 정수로 만든다.
Q5.
두 직사각형이 겹쳐서 만든 팔각형(octagon)이다. 이 팔각형의 둘레(perimeter)를 바르게 나타낸 식은?
정답: A (2p + 2r)
클로드 설명풀이
  1. 계단 모양 도형은 꺾인 선을 '밀어서' 바깥쪽 큰 직사각형 모양으로 옮길 수 있다.
  2. 가로 방향 선들을 위·아래로 밀면 위쪽 합 = p, 아래쪽 합 = p → 가로 합 2p.
  3. 세로 방향 선들을 왼쪽·오른쪽으로 밀면 왼쪽 합 = r, 오른쪽 합 = r → 세로 합 2r.
  4. q 는 안쪽으로 들어간 길이일 뿐 둘레를 바꾸지 않는다. 그래서 둘레 = 2p + 2r.
기억할 점: 직각으로 꺾인 도형의 둘레 = 그 도형을 감싸는 직사각형의 둘레 (안으로 파인 홈이 없을 때).
Q6.
수열의 n번째 항이 n/(n+1) 이다. 값이 0.92 보다 큰 첫 번째 항은?
정답: D (12/13)
클로드 설명풀이
  1. n/(n+1) > 0.92 를 푼다(inequality = 부등식).
  2. 양변에 (n+1) 을 곱한다: n > 0.92n + 0.92.
  3. 100을 곱해 소수를 없앤다: 100n > 92n + 92 → 8n > 92 → n > 11.5.
  4. n 은 자연수이므로 처음으로 되는 것은 n = 12 → 12/13.
  5. 확인: 11/12 ≈ 0.9167 (작다), 12/13 ≈ 0.923 (크다) ✓
기억할 점: n/(n+1) 은 n 이 커질수록 1 에 가까워진다.
Q7.
95, 96, 97, 98, 99 를 1, 3, 5, 7, 9 중 하나와 한 번씩 짝짓는다. 큰 수를 작은 수로 나누면 다섯 개 모두 정수가 된다. 가장 작은 답과 가장 큰 답의 차는?
정답: B (86)
클로드 설명풀이
  1. 나누어떨어져야 하므로 '누구로 나눠지나'를 본다.
  2. 97 은 소수(prime) → 1 로만 나눠진다 → 97 ÷ 1 = 97.
  3. 5 의 배수는 95 뿐 → 95 ÷ 5 = 19.
  4. 9 의 배수는 99 뿐 → 99 ÷ 9 = 11.
  5. 남은 3 과 7: 96 = 3 × 32, 98 = 7 × 14 → 32, 14.
  6. 답들은 19, 32, 97, 14, 11. 가장 큰 97 − 가장 작은 11 = 86.
기억할 점: 짝짓기 문제는 '선택지가 하나뿐인 것'부터 정한다.
Q8.
두 삼각형 PQT 와 PQR 에서 QT 와 PR 이 S 에서 만난다. ∠TPR = 20°, ∠TQR = 30°, ∠STP = y°, ∠QRS = z° 일 때 y 와 z 의 관계는?
정답: A (y = z + 10)
클로드 설명풀이
  1. 삼각형의 외각(exterior angle) = 이웃하지 않는 두 내각의 합.
  2. 삼각형 PST 에서 S 의 외각 ∠PSQ = y + 20.
  3. 삼각형 QRS 에서도 S 의 외각이 같은 ∠PSQ 이다 → ∠PSQ = z + 30.
  4. 두 식이 같은 각이므로 y + 20 = z + 30 → y = z + 10.
기억할 점: X 자로 만나는 두 삼각형은 '가운데 각'을 두 번 써서 식을 만든다.
Q9.
5²−1, 7²−1, 9²−1, 11²−1, 13²−1 중 24 로 나누어떨어지는 것은 몇 개?
정답: D (4개)
클로드 설명풀이
  1. 하나씩 계산한다.
  2. 5² − 1 = 24 → 24 × 1 ✓
  3. 7² − 1 = 48 → 24 × 2 ✓
  4. 9² − 1 = 80 → 80 ÷ 24 = 3.33… ✗
  5. 11² − 1 = 120 → 24 × 5 ✓
  6. 13² − 1 = 168 → 24 × 7 ✓
  7. 그래서 4개. (9 는 3 의 배수라 9²−1 은 3 으로 안 나눠진다. 3 의 배수가 아닌 홀수만 24 로 나눠진다.)
기억할 점: p² − 1 = (p−1)(p+1) 로 쪼개 보면 이유가 보인다.
Q10.
세 변의 비가 5 : 5 : 6 이고 넓이가 108 cm² 인 삼각형에서 가장 긴 변의 길이(cm)는?
정답: B (18)
클로드 설명풀이
  1. 세 변을 5x, 5x, 6x 라고 둔다. 이등변삼각형(isosceles)이다.
  2. 꼭짓점에서 밑변 6x 에 수선을 내리면 밑변이 3x, 3x 로 반씩 나뉜다.
  3. 반쪽 직각삼각형은 빗변 5x, 밑변 3x → 3:4:5 삼각형이라 높이 = 4x.
  4. 넓이 = ½ × 6x × 4x = 12x² = 108 → x² = 9 → x = 3.
  5. 가장 긴 변 = 6x = 18 cm.
기억할 점: 3 : 4 : 5 직각삼각형(Pythagorean triple)은 자주 나온다. 외워 두자.
Q11.
덧셈 UKMT + IMC = 2026 에서 C, I, K, M, T, U 는 서로 다른 숫자이다. T + I + C + K 의 값은?
정답: B (15)
클로드 설명풀이
  1. 자리마다 두 숫자만 더하므로 받아올림(carry)은 많아야 1 이다.
  2. 천의 자리: U + (받아올림) = 2. 백의 자리에서 K + I 가 0 이 될 수 없으므로 K + I + (받아올림) = 10 이 되어 1 을 올려 준다 → U = 1.
  3. 일의 자리에서 받아올림이 있으면 십의 자리 M + M + 1 이 홀수가 되어 끝자리 2 가 안 된다 → 일의 자리 받아올림 없음 → T + C = 6.
  4. 십의 자리: M + M 의 끝자리가 2 → M = 1 또는 6. U = 1 이므로 M = 6 (6 + 6 = 12, 1 을 올림).
  5. 백의 자리: K + I + 1 = 10 → K + I = 9.
  6. T + I + C + K = (T + C) + (K + I) = 6 + 9 = 15.
기억할 점: 복면산(cryptarithm)은 '받아올림은 0 또는 1' 을 먼저 쓰고 큰 자리부터 푼다.
Q12.
큰 사분원 OQS 에서 작은 사분원 PRT 를 빼서 색칠된 세 부분이 남았다. OPRT 는 정사각형이고 OP = 2x 이다. 색칠된 세 부분의 넓이 합은?
정답: E (πx²)
클로드 설명풀이
  1. 큰 사분원의 반지름은 OR (정사각형의 대각선) 이다.
  2. 피타고라스 정리(Pythagoras' theorem): OR² = (2x)² + (2x)² = 8x².
  3. 큰 사분원 넓이 = ¼ × π × OR² = ¼ × π × 8x² = 2πx².
  4. 작은 사분원 PRT 는 반지름 2x → 넓이 = ¼ × π × (2x)² = πx².
  5. 색칠된 부분 = 큰 것 − 작은 것 = 2πx² − πx² = πx².
기억할 점: 넓이만 필요하면 OR 을 구하지 않고 OR² 을 바로 쓰면 된다.
Q13.
노아가 1, 2, 4, 13 을 쓰고 정수 x 를 하나 더 썼다. x 가 다섯 수의 평균(mean), 중앙값(median), 최빈값(mode) 중 하나가 된다. 가능한 x 는 몇 개?
정답: E (6개)
클로드 설명풀이
  1. 평균이 되는 경우: (1 + 2 + 4 + 13 + x) ÷ 5 = x → 20 + x = 5x → x = 5.
  2. 중앙값이 되는 경우: 크기 순서로 1, 2, x, 4, 13 이 되어야 하므로 x = 2, 3, 4.
  3. 최빈값이 되는 경우: 이미 있는 수와 같으면 두 번 나와 최빈값이 된다 → x = 1, 2, 4, 13.
  4. 모두 모으면(겹치는 것은 한 번만) 1, 2, 3, 4, 5, 13 → 6개.
기억할 점: 세 경우를 따로 구한 뒤 겹치는 것을 지우고 센다.
Q14.
예각삼각형(acute-angled triangle) PQR 의 세 각(도)이 모두 삼각수(triangular number)이다. 가장 작은 각은?
정답: C (36°)
클로드 설명풀이
  1. 삼각수: 1, 3, 6, 10, 15, 21, 28, 36, 45, 55, 66, 78 … (예각이라 90 보다 작은 것만).
  2. 가장 큰 각은 60° 보다 커야 하므로 66° 또는 78°.
  3. 66° 라면 나머지 두 각의 합 114°. 둘 중 큰 각이 57° 이상이고 66° 이하라 66° → 마지막 각 48°. 48 은 삼각수가 아니다 ✗.
  4. 78° 라면 나머지 합 102°. 큰 쪽이 51° 이상 → 55°, 66°, 78° 를 해 본다: 나머지는 47°, 36°, 24°.
  5. 삼각수인 것은 36 뿐 → 세 각 78°, 66°, 36°. 가장 작은 각은 36°.
기억할 점: 삼각수 = 1, 1+2, 1+2+3, … (n(n+1)/2).
Q15.
UKMT 로고는 똑같은 평행사변형(parallelogram) 3개가 한 변이 Y 인 정삼각형을 둘러싼 모양이다. X : Y : Z = 1 : 4 : 5 일 때, 안쪽 삼각형 넓이 : 평행사변형 3개 넓이 의 비는?
정답: D (8 : 15)
클로드 설명풀이
  1. X = 1, Y = 4, Z = 5 로 두고 계산한다.
  2. 정삼각형 넓이 = ½ × Y × Y × sin 60° = ½ × 16 × sin 60° = 8 sin 60°.
  3. 평행사변형 하나: 밑변 Z = 5, 짧은 변 X = 1, 두 변 사이 각 60° → 높이 = 1 × sin 60°.
  4. 평행사변형 하나 넓이 = 5 × sin 60°, 세 개 = 15 sin 60°.
  5. 비 = 8 sin 60° : 15 sin 60° = 8 : 15.
기억할 점: sin 60° 는 양쪽에 똑같이 있어서 지워진다. 값을 몰라도 된다.
Q16.
케리와 캐런이 서로 만나러 정오에 각자 집에서 같은 속력으로 출발했다. 오후 1시에 200 km, 오후 2시 15분에 100 km 떨어져 있었다. 두 집 사이 거리는?
정답: C (280 km)
클로드 설명풀이
  1. 1시 → 2시 15분 = 75분 동안 거리가 100 km 줄었다.
  2. 그러면 60분 동안은 100 × 60/75 = 80 km 줄어든다.
  3. 정오 → 1시 (60분) 동안 80 km 줄어서 200 km 가 되었다.
  4. 출발할 때 거리 = 200 + 80 = 280 km.
기억할 점: '두 사람 사이 거리가 줄어드는 빠르기'를 하나로 보고 계산한다.
Q17.
똑같은 1 × 2 직사각형 두 개가 그림처럼 겹쳐 있다. 겹친(색칠된) 부분의 넓이는?
정답: A (5/4)
클로드 설명풀이
  1. 겹친 부분은 평행사변형이고, 높이는 직사각형의 짧은 변 1 이다.
  2. 평행사변형의 밑변(가로 직사각형 윗변 위 길이)을 x 라고 둔다.
  3. 모서리에 생긴 작은 직각삼각형은 한 변 1, 빗변 x, 다른 변 2 − x 이다 (두 삼각형이 합동이어서).
  4. 피타고라스: x² = 1² + (2 − x)² = 1 + 4 − 4x + x² → 4x = 5 → x = 5/4.
  5. 넓이 = 밑변 × 높이 = 5/4 × 1 = 5/4.
기억할 점: 겹친 부분이 마름모·평행사변형이면 '밑변 × 높이' 를 쓴다.
Q18.
그림에서 JK = JL, JN = JM, ∠KJM = 30° 이다. ∠NML 의 값은?
정답: C (15°)
클로드 설명풀이
  1. ∠JKL = α, 구하는 ∠NML = β 로 둔다.
  2. JK = JL 이라 삼각형 JKL 은 이등변 → ∠JLK = α.
  3. 삼각형 NML 에서 N 의 외각: ∠MNJ = α + β.
  4. JN = JM 이라 삼각형 JMN 은 이등변 → ∠JMN = ∠MNJ = α + β. 그래서 ∠JML = (α + β) + β = α + 2β.
  5. 삼각형 JKM 에서 M 의 외각: ∠JML = α + 30.
  6. α + 2β = α + 30 → 2β = 30 → β = 15°.
기억할 점: 모르는 각을 글자(α, β)로 두고 외각 정리를 두 번 쓰면 α 가 지워진다.
Q19.
1 + 16 / (1 + 1/(1 + 1/x)) = 11 이 되는 x 의 값은?
정답: D (3/2)
클로드 설명풀이
  1. 바깥부터 한 겹씩 벗긴다.
  2. 1 을 넘기면: 16 / (1 + 1/(1 + 1/x)) = 10.
  3. 뒤집으면: 1 + 1/(1 + 1/x) = 16/10 = 8/5.
  4. 1 을 빼면: 1/(1 + 1/x) = 3/5 → 1 + 1/x = 5/3.
  5. 1 을 빼면: 1/x = 2/3 → x = 3/2.
  6. 확인: x = 3/2 를 넣으면 11 이 나온다 ✓
기억할 점: 번분수(continued fraction)는 '바깥에서 안으로' 한 단계씩 푼다.
Q20.
이 도형의 모든 각은 45° 의 배수이고 몇 변의 길이가 주어져 있다. 도형의 둘레는?
정답: B (18 + 5√2)
클로드 설명풀이
  1. 모르는 길이 세 개를 둔다: 비스듬한 두 변 x, y 와 맨 아래 가로 변 z.
  2. 세로 방향: 비스듬한 변은 45° 로 기울어 있어 세로로 (길이 × 1/√2) 만큼 올라간다. 오른쪽에서 올라간 높이 (x + y)/√2 = 왼쪽 높이 2 + 3 = 5 → x + y = 5√2.
  3. 가로 방향: 한 바퀴 돌면 오른쪽·왼쪽으로 간 거리가 같다. z + (x + y)/√2 = 4 + 4 + 1 → z + 5 = 9 → z = 4.
  4. 둘레 = z + (x + y) + 4 + 4 + 3 + 1 + 2 = 4 + 5√2 + 14 = 18 + 5√2.
기억할 점: 45° 로 기운 길이 L 은 가로·세로로 각각 L/√2 씩 움직인다.
Q21.
x + y = 6, x³ + y³ = 198 일 때 xy 의 값은?
정답: A (1)
클로드 설명풀이
  1. (x + y)³ = x³ + y³ + 3xy(x + y) 를 쓴다.
  2. 6³ = 198 + 3xy × 6 → 216 = 198 + 18xy.
  3. 18xy = 18 → xy = 1.
기억할 점: x³ + y³ 이 나오면 (x + y)³ 전개식을 떠올린다.
Q22.
벌이 X 에서 출발해 맞닿은 육각형으로만 움직이며, 같은 곳을 두 번 가지 않고 7개 육각형을 모두 방문한다. 가능한 경로는 몇 가지?
정답: C (18)
클로드 설명풀이
  1. 바깥 6칸을 X, P, Q, R, S, T (둥글게), 가운데를 U 라고 한다. U 는 바깥 6칸과 모두 맞닿아 있다.
  2. 벌은 언젠가 U 에 들어가야 하고, U 앞뒤로는 바깥 고리를 시계방향이나 반시계방향으로만 돈다.
  3. X 바로 다음에 U: 그 뒤 시계·반시계 → 2가지.
  4. P 다음에 U (P 는 X 옆): X→P→U 다음 두 방향 2가지 + X→T→S→R→Q→P→U 1가지 = 3가지. T, Q, S 도 똑같이 3가지씩 → 4 × 3 = 12가지.
  5. R (X 의 맞은편) 다음에 U: 가는 방향 2 × U 뒤 남은 칸 순서 2 = 4가지.
  6. 합: 2 + 12 + 4 = 18가지.
기억할 점: 경우의 수는 '언제 가운데로 들어가나' 처럼 기준 하나로 나누어 센다.
Q23.
올리버가 물어본 사람 중 정확히 99% 가 수학을 좋아한다고 했다. 테레사가 다른 사람들에게 물어 합쳤더니 정확히 98% 가 '예' 였다. 테레사에게 '아니요' 라고 한 사람은 최소 몇 명?
정답: B (2명)
클로드 설명풀이
  1. 올리버의 '아니요' 가 정확히 1% → 올리버는 100n 명에게 물었고 n 명이 '아니요'.
  2. 테레사가 x 명에게 물었다고 하자. 합쳐서 '아니요' 가 2% → (100n + x) × 2/100 = 2n + x/50 명.
  3. 사람 수는 정수이므로 x 는 50 의 배수.
  4. 테레사의 '아니요' = 전체 '아니요' − 올리버의 '아니요' = (2n + x/50) − n = n + x/50.
  5. 가장 작게: n = 1, x = 50 → 1 + 1 = 2명.
기억할 점: 퍼센트가 '정확히' 라면 사람 수가 특정 수의 배수여야 한다는 뜻이다.
Q24.
K, L, M, N 은 사각형 PQRS 각 변의 중점이다. T 는 안쪽 한 점이고 KQLT, LRMT, MSNT 의 넓이가 20, 24, 15 이다. NPKT 의 넓이는?
정답: B (11)
클로드 설명풀이
  1. T 에서 네 꼭짓점 P, Q, R, S 로 선을 그으면 작은 삼각형 8개가 생긴다.
  2. 중점에서 나눈 두 삼각형은 밑변이 같고 높이가 같아서 넓이가 같다. 그래서 같은 넓이 짝 A, A, B, B, C, C, D, D 가 생긴다.
  3. 작은 사각형 하나는 서로 다른 짝 두 개로 되어 있다: MSNT = A + D = 15, KQLT = B + C = 20, LRMT = C + D = 24.
  4. NPKT = A + B = (A + D) + (B + C) − (C + D) = 15 + 20 − 24 = 11.
기억할 점: 마주 보는 두 사각형 넓이의 합은 같다: x + 24 = 20 + 15 → x = 11.
Q25.
조이는 일주일 중 서로 다른 3일을 무작위로 골라 그날만 수영한다. 수영하지 않는 날이 적어도 3일 연속으로 이어질 확률은?
정답: C (3/5)
클로드 설명풀이
  1. 수영하는 3일 사이의 '쉬는 날 수' 세 개를 본다(일주일이 돌아가므로 세 군데). 합 = 7 − 3 = 4.
  2. 합이 4 인 세 수 조합: (0,0,4) 3가지 순서, (0,1,3) 6가지, (0,2,2) 3가지, (1,1,2) 3가지 → 모두 15가지이고 똑같이 일어난다.
  3. 3일 이상 연속으로 쉬려면 3 이나 4 가 있어야 한다: (0,0,4) 3가지 + (0,1,3) 6가지 = 9가지.
  4. 확률 = 9/15 = 3/5.
  5. 확인: 7일 중 3일 고르는 35가지를 모두 세어도 21/35 = 3/5 ✓
기억할 점: 고른 날 대신 '사이 간격' 을 세면 경우가 훨씬 적어진다.
