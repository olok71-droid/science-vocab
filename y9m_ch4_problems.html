Solving Equations — Apply
Question 1: 9x = 27 의 답은 x = 3 이다. 답이 x = 3 인 서로 다른 방정식 5개를 써라.
풀이
예: x + 1 = 4,   2x = 6,   x − 3 = 0,   5x = 15,   x/3 = 1 (정답은 여러 개)
Question 2: Ronald is x years old. Colin is 3 years older and is 19. (a) 식 세우기 (b) Ronald의 나이
풀이
(a) x + 3 = 19  (b) x = 16살
Question 3: Hannah is n years old. Aunt Emily is three times older and is 48. (a) 식 (b) Hannah의 나이
풀이
(a) 3n = 48  (b) n = 16살
Question 4: Sam은 어떤 수 n에 7을 곱하고 3을 더해 45가 되었다. (a) 식 (b) n
풀이
(a) 7n + 3 = 45  (b) 7n = 42 → n = 6
Question 5: 직사각형 밭의 둘레가 150 m 이고, 가로가 세로보다 15 m 길다. 두 변의 길이는?
풀이
세로를 w 라 하면 가로는 w + 15. 둘레 = 2(w + w + 15) = 150 → 2w + 15 = 75 → 2w = 60 → 세로 30 m, 가로 45 m 둘레는 (가로 + 세로) × 2 다. 먼저 반으로 나눠 75 로 놓으면 계산이 쉽다.

Letters on Both Sides — Apply
Question 1: 직사각형의 마주 보는 변이 9x + 12 와 4x + 47 이다. (a) 왜 9x + 12 = 4x + 47 인가? (b) x 구하기
풀이
(a) 직사각형은 마주 보는 변의 길이가 같기 때문이다.
(b) 9x + 12 = 4x + 47 → 5x = 35 → x = 7
Question 2: 이등변삼각형의 두 변이 4x + 15 와 33 − 2x, 밑변이 5x 다. (a) 왜 4x + 15 = 33 − 2x 인가? (b) x (c) 둘레
풀이
(a) 이등변삼각형(isosceles triangle)은 두 변의 길이가 같기 때문이다.
(b) 4x + 15 = 33 − 2x → 6x = 18 → x = 3
(c) 두 변 = 4(3)+15 = 27, 밑변 = 5(3) = 15 → 둘레 = 27 + 27 + 15 = 69
Question 3: 8x + 3 = 2(4x + 1) 에 해가 없는 이유를 설명하라.
풀이
오른쪽을 전개하면 8x + 2 다. 즉 8x + 3 = 8x + 2 → 양변에서 8x 를 빼면 3 = 2 라는 거짓이 된다. 어떤 x 를 넣어도 성립하지 않으므로 해가 없다.

Simultaneous Equations — 활용 문제
Question 1: 커피 1잔 + 차 1잔 = £4, 커피 1잔 + 차 3잔 = £7. 각각의 값은?
풀이
c + t = 4, c + 3t = 7 → 빼면 2t = 3 → t = £1.50, c = 커피 £2.50, 차 £1.50
Question 2: Rosemary와 Hannah 나이의 합은 102, 차는 52. (Rosemary가 더 많다) 각자 몇 살인가?
풀이
R + H = 102, R − H = 52 → 더하면 2R = 154 → Rosemary 77살, Hannah 25살
Question 4: 의자 4개와 탁자 2개가 £218, 의자 6개와 탁자 7개가 £587. 의자 20개와 탁자 5개의 값은?
풀이
4c + 2t = 218, 6c + 7t = 587 → c = £22, t = £65 → 20(22) + 5(65) = 440 + 325 = £765
Question 5: 배관공의 시간당 요금 £h, 기본요금 £c. 5시간 £155, 8시간 £230. 2시간 작업은 얼마?
풀이
5h + c = 155, 8h + c = 230 → 3h = 75 → h = £25, c = £30 → 2시간 = 2(25) + 30 = £80
Question 6: 문구 200개를 £76에 샀다. 자 x개는 개당 50p, 펜 y개는 개당 20p. 각각 몇 개인가?
풀이
x + y = 200, 0.5x + 0.2y = 76 → 0.3x = 36 → 자 120개, 펜 80개 단위를 파운드로 맞춘다(50p = £0.5). 펜 개수는 200 − 120 이다.
Question 7: 바나나 4 kg + 사과 3 kg = £7.50, 바나나 3 kg + 사과 5 kg = £8.10. 바나나 2 kg + 사과 2 kg 은?
풀이
4b + 3a = 7.5, 3b + 5a = 8.1 → b = £1.20, a = £0.90 → 2(1.2) + 2(0.9) = £4.20

x 가 21부터 25까지의 정수일 때 solution set 을 구하라
a) 7x − 15 > 6x + 8   b) 5x + 23 < 3x + 71   c) 2x − 3 > 60 − x
