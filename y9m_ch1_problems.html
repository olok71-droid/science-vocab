1.1Irrational numbers무리수 · 서드(surd)
STARTER (수업 시작 문제)
Question 4: Between which two consecutive integers do each of the following lie between?
다음 수는 어떤 연속한 두 정수 사이에 있나? (예: √53 은 7과 8 사이)
(a) √20(b) √97(c) √6 (d) √41(e) √130(f) √250
풀이
(a) 4 and 5   (b) 9 and 10   (c) 2 and 3   (d) 6 and 7   (e) 11 and 12   (f) 15 and 16 푸는 법: 제곱수(square numbers)를 양옆에서 찾는다. 예 (a) 16 < 20 < 25 이므로 4 < √20 < 5. (b) 81 < 97 < 100 → 9~10. (d) 36 < 41 < 49 → 6~7. (e) 121 < 130 < 144 → 11~12. (f) 225 < 250 < 256 → 15~16.
Worksheet · Rational and Irrational Numbers (Corbettmaths 230) — Workout
Question 1: Write down 3 rational numbers
유리수 3개를 써라.
풀이
예: 5, −3/4, 0.25 (정답은 여러 개) 유리수(rational number) = 분수 a/b (b≠0)로 쓸 수 있는 수. 정수·소수(유한·순환)는 모두 유리수다.
Question 2: Write down 3 irrational numbers
무리수 3개를 써라.
풀이
예: π, √2, √5 무리수(irrational number) = 분수로 못 쓰는 수. 소수로 쓰면 끝도 없고 규칙도 없다. 제곱수가 아닌 수의 √ 는 무리수다.
Question 3: List any irrational numbers from the box below
상자 안에서 무리수만 골라라. 상자: 8, π, 2/3, √4, 1/2, √5, 0.1̇
풀이
π 와 √5 √4 = 2 라서 유리수다. 0.1̇ 는 순환소수 = 1/9 라 유리수. 8, 2/3, 1/2 도 전부 유리수.
Question 4~6: Write down an irrational number between …
Q4) 4와 6 사이 무리수   Q5) 3과 4 사이   Q6) 6과 7 사이
풀이
Q4: √20 (≈4.47) 또는 π+2  /  Q5: √10 (≈3.16) 또는 π  /  Q6: √40 (≈6.32) 사이에 있는 제곱수가 아닌 수의 √ 를 고르면 된다. 예 Q6: 6²=36, 7²=49 → 36과 49 사이 아무 수(40)의 √.
Question 7~9: Find a value
Q7) √y 가 √33 과 √50 사이의 유리수. y?   Q8) √z 가 √125 과 √150 사이의 유리수. z?   Q9) ∛a 가 ∛100 과 ∛200 사이의 유리수. a?
풀이
Q7: y = 36 또는 49  /  Q8: z = 144  /  Q9: a = 125 √가 유리수가 되려면 안의 수가 제곱수(square number)여야 한다. 33~50 사이 제곱수 = 36, 49. 125~150 사이 제곱수 = 144 (12²). ∛ 는 세제곱수(cube number)여야 하므로 100~200 사이 = 125 (5³).

Question 1: Hannah says “all integers are rational.” Is Hannah correct?
"모든 정수는 유리수다" — 맞나?
풀이
Yes, she is correct. 정수 n 은 n/1 로 쓸 수 있으니 항상 유리수다.
Question 2: Kate says “0.3333… is irrational because it is a recurring decimal.” Is Kate correct?
"0.333…은 순환소수라서 무리수다" — 맞나?
풀이
No. 0.333… = 1/3 이므로 rational 이다. 순환소수(recurring decimal)는 항상 분수로 바꿀 수 있다. 끝나지 않지만 규칙이 있으면 유리수다.
Question 3: Does this equation have rational or irrational solutions?   (2/3)x² = 40
풀이
Irrational. x = ±√60 (2/3)x² = 40 → x² = 40 × 3/2 = 60 → x = ±√60. 60은 제곱수가 아니므로 무리수.
Question 4: 5x² = k   (a) k 를 유리수 해가 되게   (b) 무리수 해가 되게
풀이
(a) k = 20 → x² = 4 → x = ±2 (rational)    (b) k = 10 → x² = 2 → x = ±√2 (irrational) x² = k/5 이므로 k/5 가 제곱수면 유리수, 아니면 무리수. (a)는 k=5,45,80… 도 정답.
Question 5: ABC is a right angled triangle. Is the length BC rational or irrational? (AB = 4cm, AC = 8.5cm)
풀이
Rational. BC = 7.5 cm 피타고라스(Pythagoras): BC² = 8.5² − 4² = 72.25 − 16 = 56.25 → BC = √56.25 = 7.5. 딱 떨어지므로 유리수.
Question 6: Show (7 − √2)(7 + √2) is rational
풀이
= 49 − 2 = 47 → rational (a−b)(a+b) = a² − b² 꼴이다. (√2)² = 2 라서 √가 사라진다.
Question 7: Find two surds that when multiplied together give a rational answer.
풀이
예: √2 × √8 = √16 = 4  (또는 √3 × √3 = 3, √5 × √20 = 10) √a × √b = √(ab). 곱이 제곱수가 되게 짝을 고르면 된다.
Question 8: Show 2√27 ÷ 5√3 is rational
풀이
= 6/5 (= 1.2) → rational √27 = √(9×3) = 3√3 이므로 2√27 = 6√3. 따라서 6√3 / 5√3 = 6/5. √3 가 약분되어 사라진다.
