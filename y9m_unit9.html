🔢 수열 만들기 Sequences

Sequence
수열
A list of numbers that follow a rule.
규칙에 따라 늘어놓은 수. 4, 4 2/5, 4 4/5, 5 1/5, …
Term
항
Each number in a sequence.
수열 안의 수 하나하나. 5, 7, 9 의 5 는 1st term.
First term
첫째 항
The number at the start of a sequence.
수열의 맨 앞 수. 그대로 쓰고 규칙을 써서 다음 항을 만든다.
Term-to-term rule
항에서 항으로 가는 규칙
The rule that changes one term into the next term.
앞 항에서 다음 항을 만드는 규칙. 'add 2/5', 'subtract 0.3'.
Next two terms
다음 두 항
The two terms that come after the last one given.
주어진 마지막 항 다음 두 수. 7.6 → 7.3, 7.
Pattern
패턴(모양 배열)
One of a set of drawings that grow by a rule.
점(dot)으로 만든 그림. Pattern 1, 2, 3 의 점 개수가 수열이 된다.
Position number
위치 번호
The place of a term in the sequence: 1st, 2nd, 3rd, …
몇 번째 항인지 나타내는 번호 n. 1, 2, 3, 4.
Position-to-term rule
위치에서 항으로 가는 규칙
A rule that uses the position number to work out the term.
위치 번호만 넣으면 그 항이 바로 나오는 규칙. term = 2 × position number + 3.
Linear sequence
선형 수열(등차수열)
A sequence whose terms go up or down by the same amount each time.
이웃한 항의 차이가 늘 같은 수열. 11, 15, 19, 23 (차이 4).
Non-linear sequence
비선형 수열
A sequence whose terms go up or down by a different amount each time.
차이가 매번 달라지는 수열. 4, 5, 7, 10, 14 (차이 1, 2, 3, 4).
Difference
차이
The amount between one term and the next.
뒤 항 − 앞 항. 줄어드는 수열은 음수(−0.3)다.
Two-step rule
두 단계 규칙
A rule with two operations done in order.
두 계산을 쓰인 순서대로. 'add 1/2, then multiply by 2' → (2 + 1/2) × 2.

📍 n번째 항 nth term

nth term
n번째 항(일반항)
A rule in n that gives any term of a sequence.
n 자리에 위치 번호를 넣으면 그 항이 나오는 식. 3n − 1.
Common difference
공차(늘 같은 차이)
The same amount added or subtracted each time in a linear sequence.
선형 수열에서 늘 같은 차이 d. nth term 은 dn + □ 꼴.
Zero term
0번째 항
The term before the first term: first term minus the difference.
첫째 항 − 차이. nth term 의 뒤 숫자가 된다. 8, 11, 14 → 8 − 3 = 5.
Substitute
대입하다
To put a number in place of a letter.
n 자리에 1, 2, 3 … 을 넣는 것. 4n + 3 에 n = 10 → 43.
Expression
식(대수식)
A group of numbers and letters with no equals sign.
등호 없는 식. 'Work out an expression for the nth term' → 3n + 5.
Tenth term
10번째 항
The term in position 10.
n = 10 을 넣은 값. 1/2 n + 12 → 17.
Mixed number
대분수
A whole number and a fraction together, such as 1 1/4.
정수와 분수를 붙여 쓴 수. n/4 의 5th term = 1 1/4.
Improper fraction
가분수
A fraction whose top number is bigger than the bottom, such as 5/4.
분자가 분모보다 큰 분수. 5/4 와 1 1/4 둘 다 맞는 답이다.

🟰 이차 수열 Quadratic

Quadratic sequence
이차 수열
A sequence whose nth term has n² in it.
nth term 에 n² 이 든 수열. 2, 5, 10, 17, 26 = n² + 1.
First differences
1차 차이
The differences between neighbouring terms.
이웃한 항의 차이. 2, 5, 10, 17 → +3, +5, +7.
Second differences
2차 차이(차이의 차이)
The differences between the first differences.
1차 차이끼리의 차이. +3, +5, +7 → +2, +2. 같으면 n² 꼴.
Squared
제곱된
Multiplied by itself, written with a small 2, such as n².
같은 수를 두 번 곱한 것(square). n² = n × n. 3² = 9 (6 이 아니다).
Serge's method
세르게 방법
Using second differences and an n² row to find an nth term.
2차 차이가 같으면 n² 줄을 쓰고, 항 − n² 이 늘 같은 수를 더한다.

⚙️ 함수 Functions

Function
함수
A rule that changes each input into one output.
입력 하나가 규칙을 지나 출력 하나가 되는 것. y = x² + 1.
Function machine
함수 기계
A diagram of boxes that shows the steps of a function.
x → ÷2 → +3 → y 처럼 상자를 차례로 지나는 그림.
Input
입력
The number that goes into a function machine.
기계에 넣는 수 x.
Output
출력
The number that comes out of a function machine.
기계에서 나오는 수 y.
Table of values
값의 표
A table that shows x values and their y values.
x 줄과 y 줄로 된 표. 빈칸(missing values)을 채운다.
Inverse
역(거꾸로)
The opposite operation that undoes another.
y 에서 x 를 구할 때 오른쪽 상자부터 반대로. +3 ↔ −3, ÷2 ↔ ×2.
Mapping diagram
대응도
Two number lines with arrows from each x to its y.
x 수직선과 y 수직선을 그리고 x 에서 y 로 화살표를 긋는 그림.
Equation
방정식(등식)
A statement with an equals sign, such as y = 5(x − 1).
등호가 있는 식. 함수 기계를 'y =' 로 쓴다.
Cubed
세제곱된
Multiplied by itself three times, written with a small 3, such as x³.
같은 수를 세 번 곱한 것(cube). 5³ = 5 × 5 × 5 = 125.

9.1 Generating sequences

수열 만들기

두 가지 규칙 — term-to-term 과 position-to-term

수열 sequence 의 수 하나하나가 항 term 이다.

① 항에서 항으로 가는 규칙 term-to-term rule — 앞 항으로 다음 항을 만든다. 'add 2'
② 위치에서 항으로 가는 규칙 position-to-term rule = nth term — 위치 번호 position number n 만 넣으면 바로 나온다. '2n + 3'

Starter 2 (점 그림 pattern): 5, 7, 9, 11
• term-to-term rule: add 2
• position-to-term rule: 2 × position number + 3 → nth term = 2n + 3

★ 'Write the term-to-term rule' 에 2n + 3 을 쓰면 틀린다. 둘을 바꿔 쓰지 않는다.

★ 함정 1 — 줄어드는 수열과 분수 항

Starter 1 a: 4, 4 2/5, 4 4/5, 5 1/5 → add 2/5
다음 두 항 next two terms: 5 1/5 + 2/5 = 5 3/5, 5 3/5 + 2/5 = 5 5/5 = 6
  ✘ 5 5/5 ← 분자가 분모와 같으면 정수로 올린다

Starter 1 b: 8.5, 8.2, 7.9, 7.6 → subtract 0.3 (= add −0.3)
다음 두 항: 7.3, 7

★ 줄어드는 수열은 '−0.3' 처럼 빼기로 쓴다. 'add 0.3' 이라고 쓰면 반대 방향이다.

★ 함정 2 — linear 인가 non-linear 인가: 차이를 전부 구한다

선형 수열 linear sequence — 차이 difference 가 늘 같다
비선형 수열 non-linear sequence — 차이가 매번 다르다

뒤 항 − 앞 항 을 하나도 빼지 않고 다 구한다.

★ 함정 3 — 두 단계 규칙은 쓰인 순서대로

두 단계 규칙 two-step rule: 쓰인 순서대로 계산한다. BIDMAS 가 아니다.
첫째 항 first term 은 그대로 쓰고 규칙을 두 번 쓴다.

✘ 2 + 1/2 × 2 = 3 ← × 를 먼저 해 버린 틀린 풀이

9.2 Using the nth term

n번째 항(일반항) 쓰기

nth term 에 n 을 대입하기

n 자리에 1, 2, 3 … 을 넣는다 = 대입 substitute.
3n 은 3 × n 이다.

Your turn Q2
• a: 4n + 3 → 7, 11, 15 · 10번째 항 tenth term = 4 × 10 + 3 = 43
• b: 2n − 5 → −3, −1, 1 · 10th = 15 ← 음수가 나와도 된다
• d: n/5 → 1/5, 2/5, 3/5 · 10th = 10/5 = 2

Worked example 9.2 b: n/4 의 5th term = 5/4 = 1 1/4
★ 가분수 improper fraction 5/4 와 대분수 mixed number 1 1/4 둘 다 맞다.

★ 함정 1 — n² 는 2n 이 아니다

n² = n × n (제곱 squared), 2n = 2 × n

• n = 2 일 때 2² = 4, 2 × 2 = 4 ← 우연히 같다
• n = 3 일 때 3² = 9, 2 × 3 = 6 ← 다르다

Worked example 9.2 a: n² + 4 → 5, 8, 13 · 10th = 10² + 4 = 104
  ✘ 3번째 항 10, 10번째 항 24 ← n² 을 2n 으로 계산한 답
Your turn Q2 e: n² − 1 → 0, 3, 8 · 10th = 99

선형 수열의 nth term 구하기 — 세 단계

① 공차 common difference d 를 구한다 → nth term 은 dn + □
② 0번째 항 zero term = 첫째 항 − d → 이것이 □
③ 확인: n = 1, 2 를 넣어 처음 항이 나오는지 본다.

Starter 4 a: 8, 11, 14, 17 → d = 3 → 3n, 8 − 3 = 5 → 3n + 5
확인 n = 2 → 6 + 5 = 11 ✓

Example: 6, 8, 10, 12 → 2n 줄 2, 4, 6, 8 과 비교 → 늘 4 크다 → 2n + 4
★ 'multiply by 2' 는 term-to-term rule 이 아니다. 6, 8, 10 의 term-to-term rule 은 add 2.

★ 함정 2 — 줄어드는 수열은 차이가 음수

Starter 4 b: 19, 14, 9, 4 → d = −5 → −5n
0번째 항 = 19 − (−5) = 24 → 24 − 5n (= −5n + 24)
  ✘ 5n + 14 ← 차이를 +5 로 본 답 (n = 1 → 19 지만 n = 2 → 24 로 커진다)

Your turn Q12
• a: 9 1/4, 9, 8 3/4 → d = −1/4 → 9 1/4 + 1/4 = 9 1/2 → 9½ − ¼n
• b: 20, 19.8, 19.6 → d = −0.2 → 20.2 − 0.2n
• d: −5, −6.5, −8 → d = −1.5 → −5 + 1.5 = −3.5 → −1.5n − 3.5

★ 0번째 항 = 첫째 항 − 차이. 차이가 음수면 더해진다(빼기의 빼기). 마지막에 n = 1, 2 로 꼭 확인한다.

이차 수열 — Serge's method

1차 차이 first differences 가 다르면 2차 차이 second differences(차이의 차이)를 본다.
2차 차이가 같으면 이차 수열 quadratic sequence → nth term 에 n² 이 들어 있다.

Serge: 2, 5, 10, 17, 26
• 1차 차이 +3, +5, +7, +9 → 2차 차이 +2, +2, +2
• n² 줄 1, 4, 9, 16 과 비교 → 늘 1 크다 → n² + 1

Your turn Q6 (모두 2차 차이 2 → n² + c, c = 첫째 항 − 1)
• a: 4, 7, 12 → n² + 3 · c: 0, 3, 8 → n² − 1 · d: −8, −5, 0 → n² − 9

★ c 를 구할 때 첫째 항에서 1² = 1 을 뺀다. 2 나 차이(3)를 빼지 않는다.
★ 1차 차이만 보고 'non-linear' 에서 멈추지 말고 2차 차이까지 간다.

9.3 Representing functions

함수 나타내기

function machine — 입력에서 출력으로

함수 기계 function machine: 입력 input x 가 상자를 왼쪽부터 차례로 지나 출력 output y 가 된다.
값의 표 table of values: x 줄과 y 줄.

Starter 5 a1: x → ÷2 → +3 → y
• x = 6 → 6 ÷ 2 + 3 = 6
• x = 11 → 11 ÷ 2 + 3 = 8 1/2

★ 함정 1 — y 에서 x 로: 오른쪽 상자부터 거꾸로

역 inverse: 오른쪽 상자부터 반대 연산을 한다.
+3 ↔ −3, ÷2 ↔ ×2, ×5 ↔ ÷5, −1 ↔ +1

Starter 5 a1 (x → ÷2 → +3 → y), y = 12
✔ 12 − 3 = 9 → 9 × 2 = 18
✘ 12 × 2 − 3 = 21 ← 왼쪽 상자부터 거꾸로 한 답

Starter 5 a2 (x → −1 → ×5 → y), y = 35
✔ 35 ÷ 5 = 7 → 7 + 1 = 8
★ 답을 다시 기계에 넣어 확인한다: (8 − 1) × 5 = 35 ✓

★ 함정 2 — 식으로 쓸 때 괄호

식 equation 은 'y =' 를 왼쪽에 쓰고 기계 순서대로 만든다.

• x → ÷2 → +3 → y : 나누고 더하기 → y = x/2 + 3
• x → −1 → ×5 → y : 먼저 빼고 그다음 곱하기 → y = 5(x − 1)
  ✘ y = 5x − 1 ← 이것은 '×5 먼저, −1 나중' 기계다

★ + 나 − 가 먼저 오고 × 가 나중이면 괄호가 꼭 필요하다.

제곱·세제곱 기계와 mapping diagram

□² = 제곱 squared, □³ = 세제곱 cubed

Worked example 9.3: x → □² → +1 → y
x 0, 1, 2, 3 → y 1, 2, 5, 10 → y = x² + 1
대응도 mapping diagram: x 수직선과 y 수직선을 그리고 0→1, 1→2, 2→5, 3→10 으로 화살표.

Your turn Q2 ii: x → □³ → −3 → y
• 1³ − 3 = −2 (1³ = 1, 3 이 아니다)
• 5³ − 3 = 125 − 3 = 122
• 10³ − 3 = 1000 − 3 = 997

★ 5³ 을 5 × 3 = 15 로 하면 틀린다. 5 × 5 × 5.
★ y = (x + 1)² 와 y = x² + 1 은 다르다. 기계 순서가 □² 먼저면 x² + 1.
