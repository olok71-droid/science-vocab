⚖️ 방정식 풀기 Solving

Equation
방정식
Two expressions joined by an equals sign.
등호(=)가 있는 식. 값을 구해 풀 수 있다.
Solve
풀다
To find the value of the unknown letter.
모르는 글자의 값을 찾아내는 것. 가장 많이 나오는 지시문이다.
Solution
해
The value that makes the equation true.
넣었을 때 식이 성립하는 값.
Unknown
미지수
The letter whose value you are looking for.
값을 모르는 글자. 보통 x 로 쓴다.
Both sides
양변
The left and the right of the equals sign.
등호의 왼쪽과 오른쪽. 무엇을 하든 양쪽에 똑같이 한다.
Balance
균형
Keeping both sides equal.
양쪽이 같은 상태를 유지하는 것. 방정식은 저울과 같다.
Inverse operation
역연산
The operation that undoes another one.
반대 연산. 더하기↔빼기, 곱하기↔나누기.
Isolate
혼자 남기다
To get the letter by itself on one side.
글자 하나만 한쪽에 남기는 것.
Coefficient
계수
The number in front of the letter.
글자 앞에 붙은 숫자. 3w 의 계수는 3.
Two-step equation
두 단계 방정식
An equation needing two inverse operations.
두 번 풀어야 하는 식. 2x + 3 = 9 같은 것.
Substitute
대입하다
To put a number in place of a letter.
글자 자리에 수를 넣는 것. 답을 검산할 때 쓴다.
Check
검산하다
To put your answer back in to see if it works.
구한 답을 다시 넣어 맞는지 보는 것.
Construct an equation
방정식을 세우다
To write an equation from a word problem.
문장을 읽고 식을 만드는 것. 4.1 단원 제목이다.
Perimeter
둘레
The total distance around the edge of a shape.
도형 둘레의 길이. 둘레 = (가로 + 세로) × 2
Rectangle
직사각형
A shape with four right angles; opposite sides are equal.
네 각이 직각인 사각형. 마주 보는 변의 길이가 같다.
Isosceles triangle
이등변삼각형
A triangle with two sides of equal length.
두 변의 길이가 같은 삼각형. 그 두 변을 같다고 놓고 식을 세운다.
Opposite sides
마주 보는 변
The sides facing each other in a rectangle.
직사각형에서 서로 마주 본 변. 길이가 같다.
No solution
해가 없다
No value of the letter makes the equation true.
어떤 값을 넣어도 성립하지 않는 것. 8x+3 = 8x+2 처럼 3 = 2 가 되면 해가 없다.

Letters on both sides
양변에 글자
The unknown appears on the left and the right.
글자가 등호 양쪽에 다 있는 식.
Collect
모으다
To bring like terms together on one side.
같은 것끼리 한쪽으로 모으는 것.
Like terms
동류항
Terms with exactly the same letters and powers.
글자와 지수가 같은 항들. 4x 와 2x 는 동류항.
Move across
반대쪽으로 넘기다
To take a term to the other side, changing its sign.
항을 반대쪽으로 옮기는 것. 부호가 바뀐다.
Expand
전개하다
To multiply out the brackets.
괄호를 풀어 곱하는 것. 5(x+3) = 5x + 15
Bracket
괄호
A symbol grouping part of a calculation.
묶음 표시. 방정식에서는 먼저 푼다.
Simplify
간단히 하다
To write the expression in its shortest form.
더 짧게 정리하는 것.
Negative answer
음수 답
An answer below zero.
답이 0보다 작은 것. 틀린 게 아니다.
Fraction answer
분수 답
An answer that is a fraction.
답이 분수로 나오는 것. 7/2 처럼 그대로 써도 된다.
Denominator
분모
The number on the bottom of a fraction.
분수 아래쪽 수. 양변에 곱해 없앤다.
Multiply both sides
양변에 곱하다
To multiply the left and right by the same number.
양쪽에 같은 수를 곱하는 것. 분수를 없앨 때 쓴다.
Explain why
이유를 설명하시오
An instruction asking for a written reason.
까닭을 글로 쓰라는 지시문. 답만 쓰면 점수가 깎인다.

🔗 연립방정식 Simultaneous

Simultaneous equations
연립방정식
Two equations that are true at the same time.
동시에 성립하는 두 식. x 와 y 를 둘 다 구한다.
Elimination
소거법
Removing one unknown by adding or subtracting the equations.
두 식을 더하거나 빼서 글자 하나를 없애는 방법.
Eliminate
없애다
To get rid of one of the unknowns.
글자 하나를 지우는 것.
Add the equations
두 식을 더하다
To add the left sides and the right sides together.
두 식을 세로로 더하는 것. 부호가 다를 때 쓴다.
Subtract the equations
두 식을 빼다
To take one equation away from the other.
두 식을 빼는 것. 부호가 같을 때 쓴다.
Same sign
같은 부호
Both terms are positive or both negative.
둘 다 + 이거나 둘 다 − 인 것. 이때는 뺀다.
Different sign
다른 부호
One term is positive and the other negative.
하나는 +, 하나는 − 인 것. 이때는 더한다.
Match the coefficients
계수를 맞추다
To multiply an equation so the numbers in front line up.
한 식에 수를 곱해 앞 숫자를 같게 만드는 것.
Substitute back
다시 대입하다
To put the found value into one equation to get the other.
구한 값을 원래 식에 넣어 나머지를 구하는 것.
Pair of values
값의 짝
The x and y that solve both equations.
두 식을 모두 만족하는 x 와 y 한 쌍.
Simultaneously
동시에
At the same time.
같은 때에. 두 식이 함께 성립한다는 뜻이다.

A statement using <, >, ≤ or ≥ instead of =.

Inequality sign
부등호
The symbol <, >, ≤ or ≥.
<, >, ≤, ≥ 기호.
Greater than
보다 크다

Less than
보다 작다
The symbol <.
< 기호. x < 5 는 x 가 5보다 작다는 뜻.
Greater than or equal to
크거나 같다
The symbol ≥.
≥ 기호. 그 값도 포함한다.
Less than or equal to
작거나 같다
The symbol ≤.
≤ 기호. 그 값도 포함한다.
Reverse
뒤집다
To turn the inequality sign the other way.
부등호 방향을 반대로 바꾸는 것.
Divide by a negative

To divide both sides by a number below zero.
음수로 나누는 것. 이때 부등호가 뒤집힌다.
Combined inequality

조건에 맞는 것.

두 값 사이의 모든 수.

4.1 Constructing and solving equations

방정식 세우고 풀기

방정식은 저울이다 — 양변에 똑같이 한다

등호는 '양쪽 무게가 같다'는 뜻이다. 그래서 무엇을 하든 양변 both sides 에 똑같이 해야 균형이 깨지지 않는다.

x 에 붙어 있는 것을 역연산 inverse operation 으로 하나씩 떼어 낸다.
더하기 ↔ 빼기   곱하기 ↔ 나누기

w + 5 = 7 → 양변에서 5를 뺀다 → w = 2
a − 1 = 6 → 양변에 1을 더한다 → a = 7
3w = 12 → 양변을 3으로 나눈다 → w = 4
w ÷ 2 = 6 → 양변에 2를 곱한다 → w = 12

두 단계짜리는 순서가 정해져 있다

더하기·빼기를 먼저 없애고, 그다음 곱하기·나누기를 없앤다.

2x + 3 = 9
→ 양변에서 3을 뺀다: 2x = 6
→ 양변을 2로 나눈다: x = 3

x/3 + 1 = 5
→ 1을 뺀다: x/3 = 4
→ 3을 곱한다: x = 12

c/2 − 4 = 6 → c/2 = 10 → c = 20

답이 분수나 음수여도 맞는 답이다

깔끔한 정수가 안 나온다고 틀린 게 아니다. 그대로 쓰면 된다.

2m + 8 = 15 → 2m = 7 → m = 7/2 (= 3.5)
4x + 11 = 3 → 4x = −8 → x = −2
3c + 8 = −13 → 3c = −21 → c = −7
m/8 + 7 = −1 → m/8 = −8 → m = −64

★ 분수 계수도 같다. ½x + 3 = 15 → ½x = 12 → x = 24 (2를 곱한다)

분수 방정식은 분모를 먼저 없앤다

분모 denominator 를 양변에 곱해 분수를 지운 다음 푼다.

(x + 1)/2 = 9 → 양변 × 2 → x + 1 = 18 → x = 17
(m − 8)/5 = 3 → m − 8 = 15 → m = 23
2x/3 = 6 → 2x = 18 → x = 9
(2x + 5)/3 = 7 → 2x + 5 = 21 → 2x = 16 → x = 8
2x/7 + 2 = 12 → 2x/7 = 10 → 2x = 70 → x = 35

★ x 앞이 마이너스면 넘겨서 양수로 만든다

−x 인 채로 풀면 부호를 틀리기 쉽다. x 를 반대쪽으로 넘겨 양수로 만들면 실수가 줄어든다.

16 − y = 5
→ y 를 오른쪽으로: 16 = 5 + y
→ y = 11

10 − 3x = 1 → 10 = 1 + 3x → 9 = 3x → x = 3
38 − 4m = 14 → 38 = 14 + 4m → 24 = 4m → m = 6
44 = 58 − 8g → 8g = 58 − 44 = 14 → g = 7/4

문장제 — 모르는 것을 글자로 놓고 식을 세운다

Ronald 가 x 살, Colin 은 3살 더 많고 19살이다.
→ 식 x + 3 = 19 → x = 16살

Hannah 가 n 살, Emily 는 세 배이고 48살이다.
→ 식 3n = 48 → n = 16살

어떤 수 n 에 7을 곱하고 3을 더해 45가 됐다.
→ 식 7n + 3 = 45 → 7n = 42 → n = 6

★ 도형 문제 — 둘레 perimeter 가 150 m, 가로가 세로보다 15 m 길다.
세로를 w 라 하면 가로는 w + 15
2(w + w + 15) = 150 → 먼저 반으로 나눠 2w + 15 = 75 → 2w = 60
→ 세로 30 m, 가로 45 m

4.1 Letters on both sides

양변에 글자가 있을 때

★ 글자를 한쪽으로 모은다 — 많은 쪽으로 모아라

양쪽에 x 가 있으면 한쪽으로 모은다. x 가 많은 쪽으로 모으면 음수가 안 생겨 편하다.

4x + 1 = 2x + 7
→ 양변에서 2x 를 뺀다: 2x + 1 = 7
→ 1을 뺀다: 2x = 6 → x = 3

6x − 3 = 2x + 13 → 4x = 16 → x = 4
x + 2 = 5x − 2 → 4 = 4x → x = 1
5x + 2 = 16 − 2x → 7x = 14 → x = 2
80 − x = 8x − 1 → 81 = 9x → x = 9

괄호가 있으면 전개부터 한다

괄호를 전개 expand 한 다음 글자를 한쪽으로 모은다.

5(x + 3) = 3(x + 9)
→ 5x + 15 = 3x + 27
→ 2x = 12 → x = 6

8(x − 1) = 4(x + 3) → 8x − 8 = 4x + 12 → 4x = 20 → x = 5
2(9 − x) = 3(x + 16) → 18 − 2x = 3x + 48 → −30 = 5x → x = −6

양쪽에 괄호가 여러 개여도 같다.
8(x − 2) − 3(1 − x) = 9(x + 2) + 1
→ 8x − 16 − 3 + 3x = 9x + 18 + 1 → 11x − 19 = 9x + 19 → 2x = 38 → x = 19

도형 문제 — '왜 같은가'를 글로 써야 한다

직사각형의 마주 보는 변 이 9x + 12 와 4x + 47 이다.
왜 같은가? → 직사각형은 마주 보는 변의 길이가 같기 때문이다.
9x + 12 = 4x + 47 → 5x = 35 → x = 7

이등변삼각형 isosceles triangle 의 두 변이 4x + 15 와 33 − 2x, 밑변이 5x 다.
왜 같은가? → 이등변삼각형은 두 변의 길이가 같기 때문이다.
4x + 15 = 33 − 2x → 6x = 18 → x = 3
두 변 = 4(3) + 15 = 27, 밑변 = 5(3) = 15 → 둘레 = 27 + 27 + 15 = 69

★ 'Explain why' 문제는 계산만 쓰면 점수가 안 나온다. 이유를 한 문장으로 적어라.

★ 해가 없는 방정식도 있다

8x + 3 = 2(4x + 1) 은 왜 해가 없나?

오른쪽을 전개하면 8x + 2 다.
→ 8x + 3 = 8x + 2
→ 양변에서 8x 를 빼면 3 = 2

3 = 2 는 거짓이다. 어떤 x 를 넣어도 성립하지 않으므로 해가 없다 no solution.
★ 글자가 통째로 사라지고 숫자만 남으면 이 경우를 의심한다.

4.2 Simultaneous equations

연립방정식 — 소거법

소거법 — 글자 하나를 없애는 것이 전부다

두 식이 동시에 성립하는 x 와 y 를 찾는 것이다. 방법은 글자 하나를 없애는 것 eliminate 이다.

부호가 같으면 뺀다. 부호가 다르면 더한다.

6x + y = 18
4x + y = 14
→ y 가 둘 다 +y (같은 부호) → 두 식을 뺀다 → 2x = 4 → x = 2
→ 원래 식에 넣는다: 6(2) + y = 18 → y = 6

9x − 4y = 19
4x + 4y = 20
→ −4y 와 +4y (다른 부호) → 두 식을 더한다 → 13x = 39 → x = 3 → y = 2

계수가 안 맞으면 곱해서 맞춘다

없애려는 글자의 앞 숫자(계수)가 같지 않으면, 한 식에 수를 곱해 맞춘다.

3x + 2y = 23
2x − y = 6
→ 두 번째 식을 ×2 하면 4x − 2y = 12
→ +2y 와 −2y 가 되었으니 더한다 → 7x = 35 → x = 5
→ 2(5) − y = 6 → y = 4

4x + 2y = 34
3x + y = 21
→ 두 번째를 ×2 → 6x + 2y = 42 → 빼면 2x = 8 → x = 4 → y = 9

푸는 순서 — 다섯 줄로 끝난다

1. 없앨 글자를 고른다(계수가 맞추기 쉬운 쪽).
2. 필요하면 한 식이나 두 식에 수를 곱해 계수를 맞춘다.
3. 부호가 같으면 빼고, 다르면 더해서 글자 하나를 없앤다.
4. 남은 글자를 푼다.
5. 구한 값을 원래 식에 다시 넣어 나머지 글자를 구한다.

★ 답은 반드시 x 와 y 두 개를 다 쓴다. 하나만 쓰면 점수를 반만 받는다.
★ 끝나면 두 값을 두 식 모두에 넣어 검산한다. 한 식만 맞아도 틀릴 수 있다.

답이 음수나 분수로 나오는 것도 정상이다

5x − 2y = −23 / 5x − 6y = −39 → x = −3, y = 4
6x + 2y = −26 / 2x + 2y = −10 → x = −4, y = −1
x − 5y = 65 / 2x − 5y = 85 → x = 20, y = −9
6x + 3y = 48 / 6x + y = 26 → x = 5/2, y = 11
3x − 6y = 6 / 2x − 6y = 3 → x = 3, y = 1/2
2x + 8y = 43 / x + 3y = 18 → x = 15/2, y = 7/2

4.3 Inequalities

부등식

부등식은 방정식과 똑같이 푼다 — 부등호만 그대로 들고 간다

부등호 inequality sign 네 개를 먼저 익힌다.
> 보다 크다  /  < 보다 작다  /  ≥ 크거나 같다  /  ≤ 작거나 같다

푸는 방법은 방정식과 같다. 등호 자리에 부등호가 있을 뿐이다.

3x − 7 < 8 → 3x < 15 → x < 5
2x − 3 ≥ 15 → 2x ≥ 18 → x ≥ 9
8x − 7 > 3x + 8 → 5x > 15 → x > 3
4x + 3 ≥ 18 − x → 5x ≥ 15 → x ≥ 3
2x + 1 ≤ 7 − x → 3x ≤ 6 → x ≤ 2

★★ 음수로 곱하거나 나누면 부등호가 뒤집힌다

이 단원에서 가장 많이 틀리는 곳이다. 방정식에는 없던 규칙이다.

−x > 2 → 양변을 −1로 나눈다 → x < −2  (> 가 < 로 뒤집혔다)
−x ≤ −5 → x ≥ 5
−2x ≥ 8 → 양변을 −2로 나눈다 → x ≤ −4
4 − 5x < 34 → −5x < 30 → x > −6
55 ≤ 22 − 11x → 33 ≤ −11x → x ≤ −3

★ 뒤집기를 피하는 법 — x 를 부호가 양수가 되는 쪽으로 넘긴 뒤 풀면 뒤집을 일이 없다.

괄호와 분수가 있으면 먼저 없앤다

8(5x − 7) − 9 ≤ 55 → 40x − 56 − 9 ≤ 55 → 40x ≤ 120 → x ≤ 3
5(3x + 2) + 6 > 91 → 15x + 16 > 91 → 15x > 75 → x > 5
4(7x + 6) − 8 ≥ 72 → 28x + 16 ≥ 72 → 28x ≥ 56 → x ≥ 2

(2x − 3)/2 ≤ 5 → 양변 × 2 → 2x − 3 ≤ 10 → 2x ≤ 13 → x ≤ 6.5
3(x + 2)/4 < 9 → 양변 × 4 → 3(x + 2) < 36 → x + 2 < 12 → x < 10

이중 부등식 — 가운데에 x 만 남긴다

1 < x + 3 < 9 처럼 양쪽에 수가 있으면, 세 부분 모두에 같은 계산을 해서 가운데에 x 만 남긴다.

1 < x + 3 < 9 → 세 곳에서 3을 뺀다 → −2 < x < 6
3 < x − 6 ≤ 10 → 세 곳에 6을 더한다 → 9 < x ≤ 16
5 ≤ 2x − 3 < 17 → 3을 더하면 8 ≤ 2x < 20 → 2로 나누면 4 ≤ x < 10

해집합(solution set) — 부등식을 푼 뒤 정수만 골라 쓴다

x 가 21부터 25까지의 정수일 때를 묻는 문제다. 순서는 둘이다.
1. 부등식을 먼저 푼다.
2. 21~25 중에서 조건에 맞는 정수만 골라 중괄호로 쓴다.

7x − 15 > 6x + 8 → x > 23 → {24, 25}
5x + 23 < 3x + 71 → 2x < 48 → x < 24 → {21, 22, 23}
2x − 3 > 60 − x → 3x > 63 → x > 21 → {22, 23, 24, 25}

★ x > 23 에는 23이 들어가지 않는다. ≥ 였다면 들어간다. 이 하나로 답이 갈린다.
