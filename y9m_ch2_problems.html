Question 1: Find the value of the formula using the numbers given
(a) T = 11(z + a), a = 2, z = 7   (b) L = 4(3c + b), c = −5, b = −6   (c) T = 4(5y + 3b + 3x), x = −3, y = 5, b = 2
풀이
(a) T = 11(7+2) = 11 × 9 = 99
(b) L = 4(3×(−5) + (−6)) = 4(−15−6) = 4 × (−21) = −84
(c) T = 4(5×5 + 3×2 + 3×(−3)) = 4(25 + 6 − 9) = 4 × 22 = 88 괄호 안을 먼저 다 계산하고 마지막에 밖의 수를 곱한다. 음수를 대입할 때는 괄호를 씌워서 부호 실수를 막는다.
Question 2: C = 2πr — radius 8 cm 인 원의 둘레 (소수 첫째 자리)
풀이
C = 2 × π × 8 = 16π = 50.265… → 50.3 cm
Question 3: A = (x/360) × πr² — radius 6 cm 인 부채꼴의 넓이 (소수 첫째 자리)
풀이
답 = 104.5 cm² 부채꼴(sector)은 원 전체의 x/360 만큼이다. 먼저 원 넓이 πr² = π × 36 = 113.097… 을 구하고, 여기에 (중심각 x ÷ 360)을 곱한다.
Question 4: s = ut + ½at² — u = 4 m/s, a = 5 m/s², t = 9 s 일 때 s
풀이
s = 4×9 + ½×5×9² = 36 + ½×5×81 = 36 + 202.5 = 238.5 m 지수를 먼저 계산한다(9² = 81). t² 는 (at)² 가 아니라 t 만 제곱하는 것이다.
Question 5: A = 2lh + 2wh + 2lw — 길이 10 cm, 폭 7 cm, 높이 5 cm 직육면체의 겉넓이
풀이
A = 2×10×5 + 2×7×5 + 2×10×7 = 100 + 70 + 140 = 310 cm²
Question 6: V = ⅓πr²h — 반지름 6 m, 높이 3 m 인 원뿔의 부피 (정수로 반올림)
풀이
V = ⅓ × π × 6² × 3 = ⅓ × π × 36 × 3 = 36π = 113.09… → 113 m³
Question 7: C = (5/9)(F − 32) — F = 13 일 때 섭씨 (정수로 반올림)
풀이
C = (5/9)(13 − 32) = (5/9)(−19) = −10.55… → −11 °C 괄호 안을 먼저 계산한다. 음수 × 양수 = 음수.
Question 8: A = P(1 + R/100)n — P = 152, R = 9, n = 7 (소수 둘째 자리)
풀이
A = 152 × (1 + 0.09)7 = 152 × 1.097 = 152 × 1.828039… = 277.86 복리(compound interest) 공식이다. 괄호 안(1.09)을 먼저 구하고 n제곱한 뒤 P를 곱한다.
2.2Constructing expressions식 세우기
Worked example 2.2 (a) Ahmad thinks of a number, n. Write an expression for:
i. 3으로 나눈 뒤 6을 뺀다   ii. 3을 더한 뒤 4를 곱한다   iii. 자기 자신과 곱한 뒤 반으로 나눈다   iv. 제곱근을 구한 뒤 5를 더한다
풀이
i. n/3 − 6    ii. 4(n + 3)    iii. n²/2    iv. √n + 5 '먼저 하는 계산'을 괄호로 묶는다. ii는 더하기를 먼저 하므로 4(n+3), 만약 4n+3 으로 쓰면 곱하기를 먼저 한 뜻이 되어 틀린다.
Worked example 2.2 (b) 가로 3x + 4, 세로 x² 인 직사각형. i. 둘레 ii. 넓이
풀이
i. 둘레 P = 2(3x+4) + 2x² = 2x² + 6x + 8
ii. 넓이 A = x²(3x+4) = 3x³ + 4x² 둘레(perimeter)는 네 변을 모두 더하고, 넓이(area)는 가로 × 세로다. 넓이에서 x² × 3x = 3x³ 처럼 지수는 더한다.
