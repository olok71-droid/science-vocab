📊 대푯값 Averages

Average
평균값(대푯값)
A single value that represents a set of data.
자료를 대표하는 하나의 값.
Mean
평균
The total of the values divided by how many there are.
값의 합을 개수로 나눈 것.
Median
중앙값
The middle value when data is put in order.
순서대로 놓았을 때 가운데 값.
Mode
최빈값
The value that appears most often.
가장 자주 나오는 값.
Range
범위
The largest value minus the smallest value.
최댓값 − 최솟값.
Data
자료(데이터)
Information collected, often numbers.
모은 정보(주로 수).
Discrete data
이산 자료
Data that can only take certain values (usually counted).
특정 값만 가지는 자료(보통 셈).
Continuous data
연속 자료
Data that can take any value in a range (usually measured).
범위 안 어떤 값이든 가지는 자료(보통 측정).

📈 자료 표현 Charts

Frequency
도수
How many times a value occurs.
값이 나온 횟수.
Frequency table
도수분포표
A table showing how often each value occurs.
각 값의 도수를 적은 표.
Tally
정(正)표시
Marks used to count data in groups of five.
다섯씩 묶어 세는 표시.
Bar chart
막대그래프
A chart using bars to show frequency.
막대로 도수를 보여주는 그래프.
Pictogram
그림그래프
A chart using pictures to show data.
그림으로 자료를 보여주는 그래프.
Pie chart
원그래프
A circle divided into sectors to show proportions.
비율을 부채꼴로 나타낸 원 그래프.
Line graph
꺾은선그래프
A graph using lines to show change over time.
시간에 따른 변화를 선으로 보여주는 그래프.
Grouped data
묶은 자료(계급)
Data sorted into class intervals.
계급(구간)으로 나눈 자료.
Modal class
최빈 계급
The class interval with the highest frequency.
도수가 가장 큰 계급(구간).

📉 산점도 Scatter

Scatter diagram
산점도
A graph of points showing two variables together.
두 변수를 점으로 함께 보여주는 그래프.
Correlation
상관관계
How two variables are related (positive, negative or none).
두 변수의 관계(양·음·없음).
Positive correlation
양의 상관
As one variable increases, so does the other.
한 변수가 늘면 다른 변수도 느는 관계.
Negative correlation
음의 상관
As one variable increases, the other decreases.
한 변수가 늘면 다른 변수가 주는 관계.
Line of best fit
추세선
A straight line drawn through the trend of scatter points.
산점도 경향을 지나게 그린 직선.
Cumulative frequency
누적도수
A running total of frequencies.
도수를 차례로 더한 합계.
Quartile
사분위수
Values that divide ordered data into four equal parts.
순서 자료를 네 등분하는 값.
Interquartile range
사분위범위(IQR)
Upper quartile minus lower quartile; the spread of the middle half.
상위 사분위수 − 하위 사분위수. 가운데 절반의 퍼짐.
Outlier
이상치
A value much larger or smaller than the rest of the data.
나머지 자료보다 훨씬 크거나 작은 값.
📊

Averages

대푯값

Mean, median, mode, range (평균·중앙값·최빈값·범위)

Mean = total ÷ how many. Median = middle value in order. Mode = most common. Range = largest − smallest.

평균=합÷개수, 중앙값=순서대로 놓은 가운데 값, 최빈값=가장 많이 나온 값, 범위=최댓값−최솟값.

📝 예시
자료: 3, 7, 4, 9, 7
평균 = (3+7+4+9+7)÷5 = 6
순서 3,4,7,7,9 → 중앙값 7, 최빈값 7
범위 = 9−3 = 6
📈

Displaying data

자료 표현

Charts (그래프와 표)

Frequency = how often a value occurs. Show data with a bar chart, pictogram, pie chart or line graph.

도수=값이 나온 횟수. 자료는 막대그래프·그림그래프·원그래프·꺾은선그래프로 나타내요.

막대그래프: 막대 높이 = 도수

📉

Scatter & spread

산점도와 퍼짐

Scatter & correlation (산점도와 상관)

A scatter diagram plots two variables. Correlation can be positive (both rise), negative (one falls) or none. A line of best fit shows the trend.

산점도는 두 변수를 점으로 찍어요. 상관관계는 양(둘 다 ↑)·음(하나 ↓)·없음이 있고, 추세선이 경향을 보여줘요.

The interquartile range (IQR) measures the spread of the middle half of the data.

사분위범위(IQR)는 자료 가운데 절반이 퍼진 정도를 재요.
