📈 함수와 그래프 Functions

Function
함수
A rule that gives one value of y for each value of x.
x 값 하나를 넣으면 y 값이 하나 나오는 규칙. y = 3x + 10.
Fixed charge
기본요금
An amount you pay once, however long you hire something.
날 수와 상관없이 한 번 내는 돈. 식에서 더하는 수가 된다. $10 → y = 3x + 10.
Per day
하루마다
For each day.
하루에 붙는 요금. 식에서 x 앞의 수가 된다. $3 per day → 3x.
Total cost
총액(전체 비용)
The whole amount you pay.
기본요금 + 하루 요금 × 날 수. 문제에서 y 또는 t 로 쓴다.
Linear function
일차 함수
A function whose graph is a straight line.
x 에 제곱이 없는 함수. y = 2x + 3, 2x + 3y = 12.
Straight line
직선
A line that does not bend.
일차 함수의 그래프. 점을 찍고 자로 곧게 긋는다.
Table of values
값의 표
A table that shows x values and their y values.
x 줄과 y 줄로 된 표. 'Copy and complete' = 빈칸을 채운다.
Plot
(점을) 찍다
To mark points on a graph using their coordinates.
표의 (x, y) 를 좌표평면에 점으로 찍는 것. Plotting graphs.
Coordinates
좌표
A pair of numbers (x, y) that gives the position of a point.
(x, y) 순서로 쓴다. 가로 x 먼저, 세로 y 나중. (6, 0).

✖️ 축과 절편 Intercepts

x-axis
x축
The horizontal axis of a graph.
가로축. x-axis 위의 점은 언제나 y = 0.
y-axis
y축
The vertical axis of a graph.
세로축. y-axis 위의 점은 언제나 x = 0.
x-intercept
x절편
The point where a graph crosses the x-axis.
그래프가 x축을 지나는 점. y = 0 을 넣어 구한다. 2x + 3y = 12 → (6, 0).
y-intercept
y절편
The point where a graph crosses the y-axis.
그래프가 y축을 지나는 점. x = 0 을 넣어 구한다. y = 2x + 3 → (0, 3).
Cross
지나다(가로지르다)
To go across a line or an axis.
'Where does this graph cross the x-axis?' = x절편이 어디인가.
Lie on the line
직선 위에 있다
A point lies on a line if its coordinates fit the equation.
점의 x 를 식에 넣어 나온 y 가 점의 y 와 같으면 Yes. (2, 5) on y = 3x − 1 → Yes.
Smooth curve
부드러운 곡선
A curved line drawn without corners through all the points.
점이 한 직선 위에 없을 때 자 없이 둥글게 잇는 선. y = x² − 3.
Root
근
A value of x where a graph crosses the x-axis.
이차 그래프의 x절편. x² − 3 = 0 → x = ±√3 ≈ ±1.73.
Symmetrical
대칭인
The same on both sides of a line.
y = x² − 3 은 y축 양쪽이 똑같다. 표의 y 도 6, 1, −2, −3, −2, 1, 6.

📐 기울기 Gradient

Gradient
기울기
How much y changes when x increases by 1.
y = mx + c 의 m. 오른쪽 위로 올라가면 +, 내려가면 −.
y = mx + c
직선의 식 y = mx + c
The general form of the equation of a straight line.
m = gradient, c = y-intercept. 직선의 식은 언제나 이 꼴로 쓸 수 있다.
General form
일반형(일반적인 꼴)
The usual way to write a type of equation.
직선은 y = mx + c 꼴. 'special general form'.
Subject
주어(혼자 남는 글자)
The letter on its own on one side of a formula.
'y as the subject' = 식을 y = … 꼴로 바꾼다. 2x + 3y = 12 → y = −⅔x + 4.
Negative gradient
음의 기울기
The gradient of a line that goes down from left to right.
오른쪽 아래로 내려가는 직선. y = 4 − 6x → gradient −6.
y-change
y 변화량
How much y goes up or down between two points.
y₂ − y₁. 내려가면 음수.
x-increase
x 증가량
How much x goes up between two points.
x₂ − x₁. gradient = y-change ÷ x-increase.
Lowest terms
기약분수(가장 간단한 꼴)
A fraction that cannot be simplified any more.
분자·분모를 더 나눌 수 없을 때까지 줄인 분수. 6/15 → 2/5.
Observation
관찰(눈으로 읽기)
Finding something by looking carefully.
'finding c through observation' = 직선이 y축과 만나는 눈금을 그래프에서 읽는다.
Straight line equation
직선의 식
The equation that every point on a straight line fits.
'Find the equation of each line' → c 와 m 을 구해 y = mx + c 로 쓴다.

🚗 그래프 해석 Interpreting

Interpreting graphs
그래프 해석하기
Working out what a graph tells you about a real situation.
실생활 그래프에서 기울기·절편이 무엇을 뜻하는지 읽는 것.
Rate of cooling
식는 빠르기
How fast the temperature goes down.
실생활 그래프의 gradient 가 rate(변화율). 1분에 4 °C 씩 식는다 → 4 °C/minute. 직선이면 rate 가 constant(일정).
Distance–time graph
거리–시간 그래프
A graph of distance travelled against time taken.
가로 time, 세로 distance. gradient = speed.
Speed
속력
The distance travelled in each unit of time.
거리 ÷ 시간. 250 m ÷ 20 s = 12.5 m/s.
In terms of
~로 나타낸(~의 식으로)
Using that letter in the formula.
'd in terms of t' = d = (t 가 든 식). d = 12.5t.
Congruent
합동인
Exactly the same shape and size.
돌리거나(rotate) 뒤집어도(reflect) 꼭 겹치는 모양. Starter 22 의 짝 찾기.

10.1 Functions

함수 — 요금 문제를 식으로

요금 문제는 y = (하루 요금)x + (기본요금)

함수 function — x 값 하나를 넣으면 y 값이 하나 나오는 규칙.

기본요금 fixed charge — 날 수와 상관없이 한 번 낸다 → 더하는 수
하루마다 per day 요금 — 날마다 붙는다 → x 앞의 수

Starter Q1: ladder, $10 + $3 per day
→ total cost y = 3x + 10 (x = 날 수, y = 달러)

★ 'Explain why y = 3x + 10' 은 영어 문장으로 이유를 쓴다:
"The cost is $3 for each day, so 3x for x days, plus the fixed charge of $10."

★ 함정 1 — one week 는 x = 1 이 아니다

x 는 날 수(days) 다. 문제 단위를 먼저 확인한다.

Starter Q1 a: one week = 7 days
✔ 10 + 3 × 7 = 10 + 21 = $31
✘ 10 + 3 × 1 = $13 ← week 를 그대로 1 로 넣은 답

★ 함정 2 — 거꾸로 풀 때는 기본요금부터 뺀다

Starter Q2 a: chainsaw, $15 + $10 per day, Aran pays $45
✔ 15 + 10n = 45 → 10n = 30 → n = 3 days
✘ 45 ÷ 10 = 4.5 ← 기본요금을 안 빼고 나눈 답

순서: ① 전체 비용 − 기본요금 (45 − 15) ② ÷ 하루 요금 (30 ÷ 10)

Starter Q2 b: 글자가 바뀌어도 꼴은 같다
비용 t, 날 수 n → t = 10n + 15
★ 문제가 준 글자(t, n)를 그대로 쓴다. y = 10x + 15 라고 쓰면 감점될 수 있다.
✖️

10.2 Plotting graphs

그래프 그리기 · 축과 절편

그래프 그리는 네 단계

일차 함수 linear function — 그래프가 직선 straight line. y = 2x + 3, 2x + 3y = 12

① x 값 몇 개를 고른다
② 식에 넣어 y 를 구하고 값의 표 table of values 에 쓴다
③ 좌표 coordinates (x, y) 를 점으로 찍는다 plot
④ 자로 직선을 긋고 점 밖으로도 늘인다

y = 2x + 3 의 표
x: −2, −1, 0, 1, 2, 3
y: −1, 1, 3, 5, 7, 9
★ x = −2 → 2 × (−2) + 3 = −4 + 3 = −1. 음수 계산에서 부호를 놓치지 않는다.

★ 함정 1 — x절편은 y = 0, y절편은 x = 0

x절편 x-intercept — 그래프가 x축 x-axis 을 지나는 cross 점 → 이때 y = 0
y절편 y-intercept — 그래프가 y축 y-axis 을 지나는 점 → 이때 x = 0

글자가 반대라서 헷갈린다. x축 위에서는 높이(y)가 0 이라고 기억한다.

y = 2x + 3
• x-axis: 2x + 3 = 0 → x = −1.5 → (−1.5, 0)
• y-axis: x = 0 → y = 3 → (0, 3)

★ 'Write the coordinates' 는 숫자 하나가 아니라 (x, y) 두 개를 쓴다. 6 이 아니라 (6, 0).

★ 함정 2 — ax + by = c 꼴은 넣고 푼다 (cover-up)

y 가 혼자 있지 않으니 x 나 y 하나를 넣고 남은 글자를 방정식으로 푼다.

Worked example 10.2: 2x + 3y = 12
• x = 0 → 3y = 12 → y = 4
• y = 3 → 2x + 9 = 12 → x = 1.5
• y = 0 → 2x = 12 → x = 6
→ x-axis (6, 0), y-axis (0, 4)

Your turn Q7: 3x + 2y = 18
x: 0, 1, 2, 4, 6 / y: 9, 7.5, 6, 3, 0
→ i. x-axis (6, 0) ii. y-axis (0, 9)

★ 표의 빈칸이 y 줄에 있으면 y 를, x 줄에 있으면 x 를 구한다(y = 7.5 → x = 1).
★ 확인: 점이 모두 한 직선 위에 있어야 한다. x 가 2 늘 때마다 y 가 3 씩 준다(9 → 6 → 3 → 0).

★ 함정 3 — x² 그래프는 곡선, 음수 제곱은 양수

Worked example 10.3: y = x² − 3
x: −3, −2, −1, 0, 1, 2, 3
y: 6, 1, −2, −3, −2, 1, 6

• (−3)² = +9 → 9 − 3 = 6 (The square of any negative number is positive.)
  ✘ −9 − 3 = −12 ← 계산기에 −3² 로 친 답. 괄호 (−3)² 를 꼭 친다

• 점이 직선 위에 없다 → 자로 잇지 말고 부드러운 곡선 smooth curve 로 잇는다
• y축 양쪽이 똑같다 = 대칭 symmetrical → 표의 y 도 6, 1, −2, −3, −2, 1, 6
• x축과 만나는 점 = 근 root: x² = 3 → x = ±√3 ≈ ±1.73 (두 개!)
• y축과 만나는 점: (0, −3)

★ 함정 4 — 점이 직선 위에 있나 (Does the point lie on the line?)

점의 x 를 식에 넣어 y 를 계산 → 점의 y 와 같으면 Yes, 다르면 No.

Add on (a): (−1, 8) on y = 2x + 11 → 2 × (−1) + 11 = 9 ≠ 8 → No
Add on (b): (12, 60) on y = 7x − 18 → 84 − 18 = 66 ≠ 60 → No

10.3 Starter
• (a) (2, 5) on y = 3x − 1 → 5 → Yes
• (d) (5, 7) on y = −3x + 22 → −15 + 22 = 7 → Yes
• (e) (−4, −8) on y = −2x → −2 × (−4) = +8 ≠ −8 → No
  ✘ Yes ← 음수 × 음수 = 양수를 놓친 답

10.3 Gradient and intercepts

기울기와 절편 — y = mx + c

y = mx + c 에서 m 과 c

직선의 식 straight line equation 은 언제나 일반형 general form y = mx + c 로 쓸 수 있다.

• m = 기울기 gradient — x 가 1 늘 때 y 가 얼마나 변하나
• c = y절편 y-intercept — x = 0 일 때 y, y축을 지나는 높이

y = 2x + 3 → gradient 2, y-intercept 3
Real life: ladder y = 3x + 10 → m = 3 = 하루 요금(rate), c = 10 = 기본요금(fixed charge)

오른쪽 아래로 내려가는 직선 = 음의 기울기 negative gradient

★ 함정 1 — 순서가 바뀌어도 x 앞의 수가 gradient (부호까지)

Your turn Q1
• a: y = 4x − 6 → gradient 4, y-intercept −6 (부호 −도 같이)
• c: y = 4 − 6x = −6x + 4 → gradient −6, y-intercept 4
  ✘ gradient 4 ← 맨 앞 숫자를 m 으로 착각한 답

★ m 은 '맨 앞 수'가 아니라 x 에 붙은 수, c 는 x 가 없는 수다.

★ 함정 2 — y 를 주어로 (y as the subject) 바꾼 뒤 읽는다

ax + by = c 꼴은 바로 읽으면 틀린다. 먼저 y = … 로 바꾼다 = y 를 주어 subject 로.
① y 가 없는 항을 반대편으로 (부호 바뀜) ② y 앞의 수로 양변 전체를 나눈다

Worked example 10.4: 2x + 3y = 12 → 3y = 12 − 2x → y = −⅔x + 4
→ gradient −2/3, y-intercept 4
  ✘ gradient 2, intercept 12 ← 바꾸지 않고 읽은 답

• d: 7x = 1 − 2y → 2y = 1 − 7x → y = ½ − 7/2 x → gradient −7/2, y-intercept 1/2
• e: 15y − 6x = 8 → y = 6/15 x + 8/15 → gradient 2/5, y-intercept 8/15
• f: ⅔x + 2y = 5 → y = −⅓x + 5/2 → gradient −1/3, y-intercept 5/2

★ 나눌 때 c 도 같이 나눈다(8 → 8/15). 분수는 기약분수 lowest terms 로 줄인다(6/15 → 2/5).

★ 함정 3 — gradient = y-change ÷ x-increase (거꾸로 나누지 않는다)

gradient = y 변화량 y-change ÷ x 증가량 x-increase = (y₂ − y₁) / (x₂ − x₁)

• a: (2, 4), (4, 10) → (10 − 4) / (4 − 2) = 6/2 = 3
  ✘ 2/6 = 1/3 ← x 를 위에 둔 답
• b: (2, 1), (4, 0) → (0 − 1) / (4 − 2) = −1/2
  ✘ 1/2 ← 내려가는 직선인데 부호를 뺀 답

★ 그래프에서는 눈금이 딱 맞는 격자점 두 개를 고른다.
★ 왼쪽 → 오른쪽으로 갈 때 내려가면 gradient 는 음수.

직선의 식 찾기 (Find the equation of each line)

① y축과 만나는 눈금을 읽어 c — 관찰 observation
② 격자점 하나를 더 골라 gradient m
③ y = mx + c 로 쓰고, 다른 점을 넣어 확인

Question 5
• (d) (0, −1), (3, 8) → m = 9/3 = 3 → y = 3x − 1
• (e) (0, 6), (6, 0) → m = −1 → y = −x + 6
• (g) (0, −4), (1, 0) → m = 4 → y = 4x − 4
• (h) (0, 3), (3, 0) → m = −1 → y = −x + 3

★ m = −1 이면 1 을 빼고 y = −x + c 로 쓴다. c 가 음수면 + 가 아니라 − 로 쓴다(y = 3x − 1).

10.4 Interpreting graphs

그래프 읽고 해석하기

실생활 그래프에서 gradient = rate, y절편 = 처음 값

그래프 해석하기 interpreting graphs — 기울기·절편이 실제로 무엇인지 말한다.

• gradient = 변화율 rate → 단위는 y 단위 ÷ x 단위 (°C/minute, m/s)
• y-intercept = 처음 값 (시작 온도, 시작 거리)
• 그래프가 직선 → rate 가 일정 constant

Worked example 10.5 (metal bar)
a. 그래프가 straight line 이라서 rate of cooling 이 constant
b. (0, 500), (50, 300) → (300 − 500) / 50 = −4
c. 1분에 4 °C 씩 식는다 — rate of cooling 4 °C/minute
d. y = 500 − 4t

★ c 'What does the gradient tell you?' 에 '−4' 숫자만 쓰면 부족하다. 단위 + 뜻을 문장으로 쓴다.

★ 함정 1 — 시간 단위를 맞춘다 (hours → minutes)

Worked example 10.5 e: 같은 빠르기로 계속 식을 때 1½ hours 뒤 온도
t 는 분(minutes) 이다 → 1½ × 60 = 90
✔ y = 500 − 4 × 90 = 500 − 360 = 140 °C
✘ 500 − 4 × 1.5 = 494 ← hours 를 그대로 넣은 답

★ 10.1 의 one week = 7 days 와 같은 함정이다. 식의 글자가 어떤 단위인지 먼저 본다.

★ 함정 2 — distance–time graph 의 gradient 는 speed

거리–시간 그래프 distance–time graph: 가로 time, 세로 distance
gradient = 거리 ÷ 시간 = 속력 speed

Your turn Q1 (car)
a. t = 20 에서 위로 올라가 읽는다 → 250 m
b. d = 200 에서 옆으로 가 읽는다 → 16 s
c. speed = 250 ÷ 20 = 12.5 m/s
d. (0, 0) 에서 시작 → c = 0 → d = 12.5t — 'd in terms of t' = d = (t 가 든 식)
e. 12.5 × 50 = 625 m

★ 격자 한 칸 = 가로 5 s, 세로 50 m. 칸 수를 그대로 답으로 쓰지 않는다.
★ 그래프 밖(50 s)은 읽지 말고 식으로 계산한다.

Starter 22 — 합동인 짝 찾기 (congruent)

합동 congruent — 돌리거나(rotate) 뒤집어도(reflect) 꼭 겹치는 모양.

짝 찾는 순서
① 조각 수를 센다 (정사각형 몇 개, 삼각형 몇 개)
② 조각이 붙은 위치를 비교한다 (같은 쪽 끝인가, 반대쪽 끝인가)

• B · C = 정사각형 4개
• D · G = 정사각형 3개 + 삼각형 1개
• A – F: 삼각형이 반대쪽 두 끝 / E – H: 같은 쪽 두 끝

★ 조각 수만 같다고 짝이 아니다. A · E · F · H 는 모두 3 + 2 개라서 ② 위치까지 봐야 갈린다.
