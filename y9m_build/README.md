# 9학년 수학 단원 페이지 만들기

`y9m_unitN.html` 의 빈 단어장(`#tab-vocab`)·핵심노트(`#tab-notes`)를 채운다.

## 쓰는 법
1. 선생님 문제 페이지 `y9m_chN_problems.html` 를 읽고, 거기 **실제로 나온** 영어 수학 용어만 뽑는다. 교과서에서 임의로 가져오지 않는다.
2. `vocabN.py` 를 만든다 — `VOCAB = [(영어, 한국어뜻, 영어정의, 한국어설명, 갈래), ...]`, `CATS = [(갈래키, 화면라벨), ...]` 갈래키는 organ·process·blood·gas 네 개만 쓴다(CSS가 이 넷만 있다).
3. `notesN.py` 를 만든다 — `NOTES = [(아이콘, 소단원제목, 부제, [(카드제목, 본문HTML), ...]), ...]`.
   선생님 문제가 노리는 **함정 위주**로 쓴다. 교과서 문장 영·한 대역 금지(2026-08-28 대표님 지시).
   한국어로 설명하되 **용어는 영어를 같이** 적는다. `<br>` 로 끊어 읽게 한다.
4. `cd ~/science-vocab-fresh && python3 y9m_build/build_unit.py N`
   발음 mp3 내려받기 → 페이지 주입 → 전체듣기·토막 mp3 생성까지 한 번에 한다.
5. `python3 check_app.py y9m_unitN.html` 로 검사하고, playwright 로 카드 수·콘솔에러 0 을 확인한다.
6. `git add -A && git commit && git push` → 라이브에서 `curl` 로 반영 확인.

## 확인된 규칙
- 토막 mp3 합계 == 전체 mp3 크기 가 무결성 검사다(차이 0이어야 한다).
- 25단어 이하 단원은 토막을 만들지 않는다.
- 기본 탭은 단어장으로 둔다(다른 단원과 같게).
