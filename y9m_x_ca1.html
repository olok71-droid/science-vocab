Q1. Circle the rational numbers. (2)
π√90.1111…4√21/3
풀이
답: √9, 0.1111…, 4, 1/3 (유리수 rational)  /  π, √2 는 무리수 irrational ① 유리수 rational number = 분수 a/b (a, b 는 정수 integer, b ≠ 0) 로 쓸 수 있는 수
② √9 = 3 = 3/1 → 유리수
③ 4 = 4/1 → 유리수, 1/3 은 이미 분수 → 유리수
④ 0.1111… 은 순환소수 recurring decimal → 1/9 로 쓸 수 있어서 유리수
⑤ 무리수 irrational number = 소수가 끝없이, 규칙 없이 이어지는 수 → π = 3.14159…, √2 = 1.41421…
⑥ 꿀팁: 루트 안이 제곱수 square number(1, 4, 9, 16, 25…)면 유리수, 아니면 무리수
Q2. Katie says “0.6666… is irrational because it is a recurring decimal”. Is Katie correct? Explain your answer. (1)
풀이
답: No. Recurring decimals can be written as fractions, so they are rational. (0.6666… = 2/3) ① 순환소수 recurring decimal 은 같은 숫자가 계속 반복되는 소수다
② 반복되는 소수는 항상 분수 fraction 로 바꿀 수 있다 → 0.6666… = 6/9 = 2/3
③ 분수로 쓸 수 있으면 유리수 rational 이다. 그래서 Katie 는 틀렸다
④ 영어 답 쓰는 법: "No, because 0.6666… = 2/3, which is a fraction, so it is rational."
Q3. Write down an estimate for √20. (1)
풀이
답: 4.5 (계산기로는 √20 = 4.472…, 4.4~4.5 정도면 된다) ① 20 양옆의 제곱수 square number를 찾는다: 16 < 20 < 25
② √16 = 4, √25 = 5 → √20 은 4 와 5 사이
③ 20 은 16 과 25 의 거의 가운데라서 약 4.5 로 어림한다 (estimate)

5.55 + 10−836 × 10−50.3 × 1056.5 × 108
풀이
답: 6.5 × 108 ① 표준형 standard form = A × 10n, 이때 1 ≤ A < 10, n 은 정수

풀이

Q7. Write 375 × 106 in standard form.  Write 0.68 × 1012 in standard form. (2)
풀이
3.75 × 108  /  6.8 × 1011 ① 앞의 수가 1~10 사이가 아니면 고쳐야 한다. 앞을 바꾼 만큼 지수를 반대로 바꾼다 (값은 그대로)
② 375 → 3.75 는 ÷100 → 106 은 ×100 = 108 → 3.75 × 108
③ 0.68 → 6.8 은 ×10 → 1012 은 ÷10 = 1011 → 6.8 × 1011
Q8. Write these numbers in order of size, smallest to largest. (2)

Q9. Simplify (m9 × m) / m5 (2)
풀이
답: m5 ① m 은 m1 이다 (지수가 안 보이면 1)
② 곱셈 법칙 multiplication law: 밑이 같으면 지수를 더한다 → m9 × m1 = m10
③ 나눗셈 법칙 division law: 지수를 뺀다 → m10 ÷ m5 = m5
Q10. Simplify c7 × (c6)4 (2)
풀이
답: c31 ① 거듭제곱의 거듭제곱 power of a power: 지수를 곱한다 → (c6)4 = c24
② 곱셈은 지수를 더한다 → c7 × c24 = c31
③ 흔한 실수: (c6)4 를 c10 으로 더해 버리는 것
Q11. Work out the value of (29 × 2−2) / 23 (2)
풀이
답: 16 ① 위: 29 × 2−2 = 29 + (−2) = 27
② 나누기: 27 ÷ 23 = 24
③ "value 값" 을 물었으니 끝까지 계산한다: 24 = 2 × 2 × 2 × 2 = 16
④ 음수 지수 negative index 를 더할 때는 빼기와 같다: 9 + (−2) = 7

Q12. Expand and simplify (x + 9)(x − 1) (3)
풀이
답: x2 + 8x − 9 ① 두 괄호 전개 expanding double brackets: 앞 괄호의 각 항을 뒤 괄호의 각 항에 곱한다 (FOIL)
② x × x = x2, x × (−1) = −x, 9 × x = +9x, 9 × (−1) = −9
③ 모으면 x2 − x + 9x − 9
④ 같은 항 정리 collect like terms: −x + 9x = 8x → x2 + 8x − 9
Q13. Expand and simplify (w + 3)(w + 4) + (w + 2)(w + 7) (3)
풀이
답: 2w2 + 16w + 26
⚠ 확인 필요 채점표 사진에서 문제 줄이 잘려, 식은 선생님 풀이(w2 + 4w + 3w + 12, w2 + 7w + 2w + 14)에서 거꾸로 맞췄다. ① 첫 번째: (w + 3)(w + 4) = w2 + 4w + 3w + 12 = w2 + 7w + 12
② 두 번째: (w + 2)(w + 7) = w2 + 7w + 2w + 14 = w2 + 9w + 14
③ 둘을 더한다: w2 + w2 = 2w2, 7w + 9w = 16w, 12 + 14 = 26
④ 답 2w2 + 16w + 26
Q14. Simplify 5/x + 7/(6x) (3)
풀이
답: 37 / (6x) ① 대수분수 algebraic fractions 더하기도 보통 분수처럼 분모를 같게 common denominator 만든다
② 공통 분모는 6x → 5/x 의 위아래에 6 을 곱한다: 5/x = 30/(6x)
③ 30/(6x) + 7/(6x) = 37/(6x)
④ 분모는 더하지 않는다 — 분자 numerator 만 더한다
Q15. Express as a single fraction (3x + 1)/4 + (2x − 1)/3 (3)
풀이
답: (17x − 1) / 12 ① 공통 분모 common denominator = 4 × 3 = 12
② (3x + 1)/4 → 위아래 ×3 → (9x + 3)/12
③ (2x − 1)/3 → 위아래 ×4 → (8x − 4)/12
④ 분자를 더한다: 9x + 3 + 8x − 4 = 17x − 1
⑤ 괄호째로 곱해야 한다! 3 × (3x + 1) = 9x + 3 (3x 에만 곱하면 틀린다)
Q16. P = 2W + 2L. Find P if W = 3 and L = 9. (2)
풀이
답: 24 ① 대입 substitution: 글자 자리에 수를 넣는다
② 2W = 2 × 3 = 6, 2L = 2 × 9 = 18
③ P = 6 + 18 = 24
④ P = 2W + 2L 은 직사각형 둘레 perimeter 공식이다 (가로 2번 + 세로 2번)
Q17. P = 2W + 2L. Find W if P = 30 and L = 11. (2)
풀이
답: W = 4 ① 아는 수를 넣는다: 30 = 2W + 2 × 11 = 2W + 22
② 양변에서 22 를 뺀다: 2W = 8
③ 양변을 2 로 나눈다: W = 4
④ 확인 check: 2 × 4 + 2 × 11 = 8 + 22 = 30 ✓
